# v1.6 核心自绘字体（font-to-core）设计

> 状态：设计待审（brainstorming 产出）。依据见 `docs/roadmap/rmlui-research.md §1`（RmlUi 深读取证）、`docs/roadmap/roadmap.md §2.2`。
> 范围：v1.6 = 内部阶段 a→b（a 管线打通 / b CJK 生产可用）；FontEffect（描边/发光/blur）推 v1.8，但 atlas key 预留 effect 维度。
> 不碰代码直至本 spec 经 writing-plans 落成任务计划。

---

## 1. 背景与目标

LoomGUI 立项根基是"引擎无关纯 Rust 核心 + 多后端"。当前唯一破例：**文本 mesh 后端光栅化**——核心只产 `TextLayout`（测量 + 断行），Unity 后端用动态字体 `RequestCharactersInTexture` / `GetCharacterInfo` 光栅化产 UV（`TextRasterizer.cs`）。这导致：

- **双源不对称**：同一 .ttf 字节喂 Rust 测量 + 喂 Unity Font asset 光栅（`LoomStageDriver.cs:113-133`）。坑 119（CJK 缺字 advance 不匹配）的根因。
- **坑 113**（atlas rebuild 时序）：Unity `Font.textureRebuilt` 异步事件，需 `_fontVersion` 版本号 + 强制 text 全 Full 重建补偿（`MirrorPool.cs:91-94,158-162` / `LoomStage.cs:118-123`）。
- **text 永不合批**：`NodePayload::Text`（program=1）在 `merge_meshes` 被跳过（`merge.rs:41`）；后端每节点独立 GameObject+MeshRenderer。
- **跨引擎不可移植**：接 Godot 须重写整条文本光栅化。

**v1.6 目标**：把光栅化搬进核心。核心用 ttf-parser 取轮廓 + ab_glyph_rasterizer 光栅 R8 + etagere 货架分配产字形 atlas + per-glyph UV；后端降为"atlas 贴图上传器"。**补齐引擎无关纯核心的最后破例**。

**收益**：根治坑 113/119、重开 kerning、text 可合批、跨引擎文本一致（接 Godot 直接受益）。**不**解决富文本嵌套（那是 v1.7 IFC 布局问题，与光栅正交，见 rmlui-research §1.2）。

## 2. 现状（file:line 证据）

**核心侧（只测量，不产像素/UV/几何）**：
- `measure_text`（`loomgui_core/src/text/layout.rs:171-377`）：ttf-parser 取度量 + unicode-linebreak 断行，产 `TextLayout{lines→runs→glyphs{glyph_id,codepoint,x,y,bearing_x,bearing_y}}`。kerning 当前硬关（`layout.rs:213` 闭包 `|_,_| None`），缺字 advance 兜底 font_size（`layout.rs:220-229`，坑 119 hack）。
- `FontTable`（`layout.rs:106-155`）：CSS family → `Arc<Font>`，进程级单字体，无 fallback。
- `NodePayload::Text{layout,font_size,color,program:1,family}`（`render/node.rs:56-64`）。
- blob text_arena 每字形只序列化 `{codepoint:u32,x:f32,pen_y:f32}`（`loomgui_ffi_c/src/blob.rs:209-214`）——无 UV/几何/bearing。VERSION=9，22 列。
- `merge_meshes`：program≠0 永不合批（`render/merge.rs:12-26`）。
- 依赖（`loomgui_core/Cargo.toml`）：`ttf-parser=0.20` + `unicode-linebreak=0.1`。**无 ab_glyph/etagere**。

**Unity 后端（光栅化器）**：
- `TextRasterizer.BuildMesh`（`TextRasterizer.cs:29`）：`RequestCharactersInTexture`（`:43`）+ `GetCharacterInfo`（`:55`）取像素 box + UV。**UV 100% 来自 Unity**。
- 坑 113 补偿：`LoomStage._fontVersion`（`:45`）+ `OnFontRebuilt`（`:123`）+ `Font.textureRebuilt +=/-=`（`LoomStageDriver.cs:84,199`）+ MirrorPool fontDirty 强制升 Full（`MirrorPool.cs:91-94,158-162`）。
- text 材质：`MaterialManager.Get(program:1, font.material.mainTexture, ...)`（`MirrorPool.cs:217`），program=1 开 `ALPHA_MASK` keyword（`MaterialManager.cs:37`）——font atlas 是 alpha-mask（rgb 黑、glyph 在 alpha）。
- blob C# 镜像：`readonly struct FrameBlob(byte[])` + `BitConverter` 直读（`FrameBlob.cs:18-27`，依赖 Windows 小端）。text 段布局 `FrameBlob.cs:187-215`，12B/glyph。
- 纹理解析链：`path_idx` → `FrameBlob.ReadPath`（`FrameBlob.cs:114-131`）→ `SpriteResolver.GetSprite`（`MirrorPool.cs:112-121`，**仅 kind==1 分支**）→ `sp.texture`。`loomgui://` scheme 仓库零先例。

## 3. 非目标

- **富文本 / 行内混排（IFC）**：v1.7。光栅化搬核心一行都不解决它（rmlui-research §1.2①③）。
- **跨字体 fallback**：v1.7（多字体天然场景）。v1.6 缺字走权威 .notdef，不做字体替换。
- **FontEffect（描边/发光/blur/shadow）**：v1.8。v1.6 仅在 atlas key 预留 `effect_sig` 维度。
- **彩色 emoji（COLR/CBDT）**：ab_glyph 只出灰度。亚洲首发 emoji→tofu 已砍。
- **复杂 shaping（rustybuzz）/ BiDi**：仍砍。
- **BMFont**：不做（动态字体已主流）。

## 4. 架构总览（数据流）

```
measure_text（纯函数，零副作用，taffy MeasureFunc 可反复调）
  ├─ ttf-parser：advance / ascent / descent / line_gap / glyph bbox / kern 表（重开）
  ├─ unicode-linebreak 断行（CJK 逐字）
  └─ 产 TextLayout（glyphs 带绝对坐标 + bearing）         ← 不光栅

render build（Stage 持可变 GlyphAtlas，跨帧状态）
  ├─ 对每个 Text 节点的每个 glyph：
  │    atlas.ensure(font_id, gid, size_px, effect_sig=0)
  │      ├─ miss → ttf-parser outline_glyph(gid) → ab_glyph 光栅 R8 → etagere 分配槽 → 标脏页
  │      └─ hit  → 返 (page_idx, uv)
  ├─ 字形按 page_idx 分组，每组产一个 Mesh（4 顶点/字，UV 指 atlas 槽，program=1）
  └─ 缺字（gid 0）→ 权威 .notdef（字体 gid0 有轮廓则光栅，否则确定性 tofu 框）

FFI（pull 模型）
  ├─ blob v10：text 塌进 mesh_arena；path 表含 loomgui://font-atlas/... 合成条目
  └─ 独立 atlas FFI：backend tick 内拉脏页 R8 字节 → 上传 Texture2D → 注册 Sprite

Unity 后端（贴图上传器）
  ├─ LoomStage.Tick：borrow_frame 后、Sync 前，调 SyncFontAtlas() 上传脏页
  ├─ text mesh（kind==1）走现有 Sprite 查询：loomgui:// 命中 SpriteResolver 缓存 → sp.texture = atlas
  └─ 删 TextRasterizer / 坑 113 补偿链 / G6 双源 Font asset 路径
```

**核心不变量守住**：measure 仍是纯函数（光栅+atlas 副作用在 Stage）；tick 时序不变；坐标系不变；代际 NodeId 不变。

## 5. 核心组件设计

### 5.1 GlyphAtlas（核心新组件）

Stage 持有可变 `GlyphAtlas`，跨帧。单物理 etagere 实例。

**glyph key（四维，RmlUi 锁定）**：
```rust
struct GlyphKey {
    font_id: u32,
    glyph_id: u16,
    size_px: u16,       // 取整后的有效 px（per-size 分片，不跨 size 共享 bitmap——质量）
    effect_sig: u64,    // v1.6 恒 0（base layer）；v1.8 填 effect 指纹哈希。预留维度，不改结构
}
```

> **为何预留 effect_sig（RmlUi 教训）**：RmlUi 每个 `HasUniqueTexture()==true` 的 effect（Outline/Blur/Glow）占独立 atlas 槽位集——base「中」与 outline「中」是两个独立矩形（`FontFaceLayer.cpp:69-98, 131-150`）。Shadow 例外（clone-offset，不占槽，`FontEffectShadow.cpp:19-22`）。v1.6 不预留 → v1.8 加 FontEffect 必改 key → 全 atlas invalidate 重光栅（灾难）。v1.6 `effect_sig=0`，v1.8 填 `hash(effect_type, params)`，key 结构不变、atlas 不 invalidate。

**多页**：etagere 单页（4096² R8 ≈ 16MB）放不下开新页，每页一张纹理。glyph 返 `(page_idx, uv_rect)`。一张 4096² 容 3000-4000 CJK 字形 @48px（rmlui-research §1.4）。

**增量（避开 RmlUi O(N²)）**：etagere `allocate` 不 repack，新字形只占新槽，**旧字形 UV 永不变**。RmlUi 全重建根因纯粹是"排序 shelf 不变量 + 无增量 API + monolithic 纹理"（`FontFaceLayer.cpp:22-23` 源码 `@performance` 自认"本可以更聪明"），**无 layer 合并/effect 排序的更深理由**。etagere 同时绕开三者，且 LoomGUI 无 layer 创建顺序依赖（额外简化）。

**脏页追踪**：`dirty_pages: Vec<page_idx>`。新字形分配标所在页脏。backend pull 后清。

**per-size / DPI**：size 进 key（跟 RmlUi `FontFace.h:31-33` 每 size 一套——hinting/snap-to-grid 让同字形不同 px 像素覆盖不同，不能光栅一次再缩放）。DPI/display_scale 在调用方乘进 effective size 再取整，**不进 atlas 层**。非整数 px 取整（AI 可预测性优先，跟 RmlUi）。

### 5.2 measure 纯函数性

`measure_text` 保持纯函数（taffy MeasureFunc 反复调，须廉价无副作用）。光栅 + atlas 分配是状态ful副作用，放 render build 期 Stage 持有的 GlyphAtlas，**不进 measure**（rmlui-research §1.5）。measure 只用 ttf-parser 度量。

### 5.3 text → Mesh payload（删 Text 变体）

**删 `NodePayload::Text`**。Text 节点变 `NodePayload::Mesh{verts,uvs,colors,indices,image_path:Some(synthetic),program:1,color_matrix:[0;20]}`。

- **UV**：每字形 4 顶点，UV 指向 atlas 槽位（etagere 分配的子区域）。
- **颜色**：per-vertex text color（同当前，alpha 走 `_Alpha` uniform 不烤顶点）。
- **atlas 纹理引用**：合成路径 `"loomgui://font-atlas/f<font_id>/p<page_idx>"` intern 进**现有 path_idx 表**（`blob.rs intern_path`）。→ **零新 blob 列、零 payload enum 结构改（除删 Text 变体）、零 merge_key 结构改**。
- **合批**：`merge_meshes` 放开守卫 `program == 0` → `program ∈ {0,1}`（program 仍在 key，text 与 image 不跨合）。同 atlas 页的 text 节点现可合并。

> **RmlUi 验证**：text 当 vanilla mesh 与 RmlUi 同构（`MeshUtilities.cpp:15-49` GenerateQuad，每字形 4 顶点 6 索引、单色烤顶点、UV 来自 per-character TextureBox）。LoomGUI 把 text 并进单一 RenderNode Mesh payload 比它更激进，方向一致。RmlUi text 永远独立 mesh；LoomGUI 让同 atlas 页 text 合并是改进非倒退。

## 6. FFI 契约改版（blob v9 → v10）

### 6.1 blob 列变更
- **删**：`text_off` / `text_len` 列（当前 col 15/16）+ `text_arena` header（`text_arena_off/len`）+ `NodePayload::Text` arm。text 字形现走 mesh_arena。
- **改**：path_idx 表新增 `loomgui://font-atlas/...` 合成条目（`intern_path` 零改复用）。
- **列数**：22 → 20（删 text_off/text_len）。VERSION 9 → 10。
- C# 镜像同步（坑 35）：`FrameBlob.cs` 列 offset 重算（`12 + 20*4 + ...`），删 `ReadText` / text 段布局（`FrameBlob.cs:187-215`）。csbindgen 不为 blob 生成镜像，手补。

### 6.2 atlas 传输 FFI（新增，pull 模型）
独立于 frame blob（atlas 字节量远超 frame blob，不挤 `_frameBuf` ArrayPool）。复用"核心只认 TexId / 路径字符串"边界——atlas 页注册为合成路径，backend 上传后挂 SpriteResolver 缓存。

```c
// 返当前脏页 page_idx 列表（写入 out，返实际数）。
size_t loomgui_stage_font_atlas_dirty_pages(StageHandle*, uint32_t* out, size_t max);
// 读某页：尺寸 + R8 像素。buf 太小返所需大小（双调法）。
size_t loomgui_stage_font_atlas_page(StageHandle*, uint32_t page_idx,
                                     uint32_t* out_w, uint32_t* out_h,
                                     uint8_t* out_buf, size_t buf_len);
// backend 拉完标清脏。
void loomgui_stage_font_atlas_clear_dirty(StageHandle*);
```

csbindgen 生成 C# 绑定（坑 35 手补镜像）。FFI 入口不 panic（坑 102：scene=None 等早返空）。

### 6.3 payload_hash 零改
已 hash verts/uvs/colors（坑 56/75/76 全量不采样），text mesh 自动受益。新字形首现触发 Full（UV 变），其后 Skip（etagere 不 repack → UV 永不变）。

## 7. Unity 后端

### 7.1 挂点
`LoomStage.Tick`（`LoomStage.cs:159-192`）在 `borrow_frame`（`:164-175`）之后、`_pool.Sync`（`:177`）之前插 `_stage.SyncFontAtlas()`：
1. `loomgui_stage_font_atlas_dirty_pages` 拉脏页列表。
2. 逐页 `loomgui_stage_font_atlas_page` 拉 R8 字节（独立 buf）。
3. `new Texture2D(w,h,TextureFormat.R8,mipChain:false)` + `SetPixelData<byte>` + `Apply(false, makeNoLongerReadable:true)`。
4. `Sprite.Create` 全区域包装 → `SpriteResolver.RegisterFontAtlasPage("loomgui://font-atlas/f<id>/p<n>", sprite)` 进缓存。
5. `loomgui_stage_font_atlas_clear_dirty`。

> 必须在 Sync 前：否则 MirrorPool 查材质吃到旧/空纹理，错误 Material 入 `MaterialManager` 缓存（`:41`）。

### 7.2 纹理解析（MirrorPool 零改）
text 变 kind==1 后自动进 `MirrorPool.cs:110` Sprite 查询分支。`GetSprite("loomgui://...")` 命中 SpriteResolver 缓存（step 4 注册）→ `sp.texture`（`:119`）= atlas Texture2D。**MirrorPool 纹理 fetch 零改**。`MaterialManager.Key` 含 texture 引用（`:74`），atlas Texture2D 自动产独立 Material 实例，不污染 Image 材质缓存。

### 7.3 shader（一行改）
**修正"零 shader 改"过度乐观**：R8 纹理覆盖在 `.r` 通道，但现有 `ALPHA_MASK` keyword 采 `.a`（`MaterialManager.cs:37`）。R8 下 GPU 采样 `.a` 恒 1（`DXGI_FORMAT_R8_UNORM` 只 R 通道，GBA 默认 (0,0,1)），会画实心方块。两条路：
- **(a) R8 + shader 一行改（推荐）**：`LoomGUI-Unlit.shader` ALPHA_MASK 块 `tex.a` → `tex.r`。省内存（1B/px），代价一行 shader。
- **(b) 零 shader 改**：上传成覆盖在 alpha 的格式（RGBA32 rgb=white/a=coverage，或 Alpha8——但 Unity 2023+ obsolete，不推荐）。4× 内存。

stage a 在 Unity 6.5 实测定（a）。Alpha8 废弃风险 + R8 内存优势 → 倾向 (a)。

## 9. 缺字 / kerning / 坑修复

**缺字（权威 .notdef，已定）**：codepoint → gid 0 时，光栅字体 gid0 轮廓；gid0 空（无 outline）则画确定性 tofu 框（advance = gid0 advance 或 `size/3 + 2` 兜底，font-independent 确定性）。不做跨字体替换（推 v1.7）。删坑 119 hack（`layout.rs:220-229` 兜底 font_size 匹配 Unity fallback）。AI 可预测：缺字 = 确定 tofu，不再猜 Unity 系统 fallback。

**kerning 重开**：`face.tables().kern` 读字距（`layout.rs:210-213` 注释已留 API），`pen += kerning(prev,cur) + advance + letter_spacing`（跟 RmlUi `FontFaceHandleDefault.cpp:76,228-240` 顺序）。删 `|_,_| None` 闭包。反转 `kerning_disabled_*` 测试（AV kern 现应生效：V.x = advance(A)+kern < advance(A)）。ASCII 32-126 预缓存可选优化（跟 RmlUi `FontFaceHandleDefault.cpp:284-303`），v1.6 先 on-demand，性能不够再加。

**坑收尾**：113 消失（无 textureRebuilt 异步）、119 根治（核心权威 advance）、114 验证（pen_y=baseline 已修，搬后仍成立）。

## 12. 风险与权衡

| 项 | 风险 / 权衡 |
|---|---|
| etagere 增量 packing 密度 < RmlUi 排序 shelf | ~80-90% 密度换增量性。LoomGUI 双 hash 检测变更，全重建会触发大量 Full（位置变→重建 mesh），增量只触发单字形。正确取舍。 |
| R8 + shader .r vs Alpha8 | R8 省 4× 内存但一行 shader 改；Alpha8 零改但 obsolete + 4×。倾向 R8+.r，stage a 实测定。 |
| 多页 text 跨页 | 单 text 节点字形跨多页 → 拆多 mesh → 多 draw call。单字体单尺寸常见一页装下，罕见。escape valve 可接受。 |
| atlas 有状态破坏 measure 纯函数 | 已规避：atlas 放 Stage render build 期，measure 零副作用。 |
| ABI 大改（blob v10） | 家里机干净 pull 须重编 .dll（坑 10）+ FFI 符号自查（坑 100）。两台机串行工作流覆盖。 |
| effect_sig 预留增 key 体积 | key 从 (font,gid,size) → 多 u64。atlas 条目数有限，可忽略。换 v1.8 不 invalidate atlas。 |

## 13. RmlUi 对标取证摘要（决策依据）

- text 当 vanilla mesh：与 RmlUi 同构（`MeshUtilities.cpp:15-49`）。A 方向正确。
- etagere 增量避全重建：RmlUi 全重建根因 = 排序 shelf + 无增量 API + monolithic（`FontFaceLayer.cpp:22-23` @performance 自认），无更深理由。etagere 绕开。✅
- per-size atlas：RmlUi 严格 per-size（`FontFace.h:31-33`），质量被迫。跟随。✅
- effect_sig 预留：RmlUi 每 effect 独立 atlas 槽（`FontFaceLayer.cpp:69-98`），Shadow clone-offset（`FontEffectShadow.cpp:19-22`）。必预留。✅
- kerning 顺序：kerning(prev,cur) + advance + letter_spacing（`FontFaceHandleDefault.cpp:76,228-240`）。跟随。
- 缺字：RmlUi 不画 .notdef，画 U+FFFD tofu 框（`FreeTypeInterface.cpp:262-287`）。LoomGUI 取"光栅字体 gid0，空则 tofu 框"。
- atlas 传输：RmlUi lazy push（CallbackTextureSource，`FontFaceLayer.cpp:131-149`）。LoomGUI pull（独立 FFI，契合现有 tick 模型）。

**完整证据见 `docs/roadmap/rmlui-research.md §1` + 本次 RmlUi 深读 agent 报告。**
