# v1.4-b: position:absolute 围栏 + 虚拟化列表 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 LoomGUI 围栏加 `position:absolute` + inset（解 tips overlay），并实现层 B' 虚拟化列表（核心不认识列表、reuse_key 复用、driver 轮询、支持等高+不等高），为背包/排行榜/邮件铺路。

**Architecture:** 两项协同——absolute 让列表 slot 脱离 flex 流精确定位到真实 item 位置。列表用层 B'：核心只多管 `reuse_key: u32` 字段（传给后端复用 GO）+ 3 个 FFI 口子（set_content_size / get_node_layout_rect / get_scroll_pos），driver 管所有列表逻辑（slot 映射、可见区间、尺寸补偿）。核心不引入 NodeKind::List、不碰包格式。

**Tech Stack:** Rust 2021（loomgui_core / loomgui_ffi_c）、taffy 0.5.2、csbindgen、C#/Unity 6.5 URP。围栏真相源 `loomgui_core/tests/fence_contract.rs`。

pub fn set_content_size(&mut self, node: NodeId, w: f32, h: f32) {
    if let Some(scene) = self.scene.as_mut() {

```csharp
// 等高虚拟列表 driver（v1.4-b T8）。
// 模型：列表容器 = instantiate("showcase","list_container")。
// slot = instantiate("showcase","list_item") + set_reuse_key(slot_id+1) + position:absolute。
// driver 每帧：get_scroll_pos 算可见区间 → diff slot 绑定 → instantiate/remove/set_text。
sealed class VirtualListDriver
{
    readonly LoomStage _stage;
    readonly uint _listContainer;      // 列表容器 NodeId
    readonly uint _itemCount;          // 总 item 数
    float _itemSize;                   // 单 item 高（首帧测量后填）
    readonly Dictionary<uint, (uint slotNodeId, uint itemIndex)> _slots = new();
    // slot_id → (当前绑定的 slot NodeId, item index)

    public VirtualListDriver(LoomStage stage, uint container, uint itemCount)
    {
        _stage = stage; _listContainer = container; _itemCount = itemCount;
    }

    // 初始化：测 itemSize + set_content_size。调两次（首帧 + 次帧，因 itemSize 要等 solve）。
    public void InitMeasure()
    {
        if (_itemSize > 0) return;
        // 测量用 item 已 instantiate 挂容器（或临时 instantiate）。
        // 等 solve 后读 layout_rect。
        var r = _stage.GetNodeLayoutRect(_measureItem);
        if (r.h > 0) { _itemSize = r.h; _stage.SetContentSize(_listContainer, 0, _itemCount * _itemSize); }
    }

    // 每帧调：算可见区间 + diff slot 绑定。
    public void SyncSlots()
    {
        if (_itemSize <= 0) { InitMeasure(); return; }
        var (sx, sy) = _stage.GetScrollPos(_listContainer);
        var vp = _stage.GetNodeLayoutRect(_listContainer);
        int first = (int)Math.Floor(sy / _itemSize);
        int last = (int)Math.Floor((sy + vp.h) / _itemSize);
        first = Math.Max(0, first); last = (int)Math.Min(_itemCount - 1, last);

        // 算可见 slot 集合 [first..last]
        var visible = new HashSet<uint>();
        for (int idx = first; idx <= last; idx++) visible.Add((uint)idx);

        // 移除离开的 slot
        var remove = new List<uint>();
        foreach (var kv in _slots)
            if (!visible.Contains(kv.Value.itemIndex)) remove.Add(kv.Key);
        foreach (var sid in remove) { _stage.RemoveNode(_slots[sid].slotNodeId); _slots.Remove(sid); }

        // 新建/更新进入的 slot
        for (int idx = first; idx <= last; idx++)
        {
            uint itemIndex = (uint)idx;
            uint slotId = itemIndex;  // 等高：slot_id = item_index
            if (!_slots.ContainsKey(slotId))
            {
                uint slot = _stage.Instantiate("showcase", "list_item");
                _stage.AppendChild(_listContainer, slot);
                _stage.SetReuseKey(slot, slotId + 1);  // reuse_key = slot_id+1（0 保留）
                float top = itemIndex * _itemSize;
                _stage.SetStyle(slot, $"position:absolute;left:0;width:100%;height:{_itemSize}px;top:{top}px");
                _slots[slotId] = (slot, itemIndex);
            }
            // 填数据（set_text title）
            _stage.SetText(_slots[slotId].slotNodeId, GetItemTitle(itemIndex));
        }
    }
    string GetItemTitle(uint i) => $"Item {i}";
    // _measureItem / 不等高逻辑见 Step 4。
}
```

注：`_stage.Instantiate/AppendChild/RemoveNode/SetReuseKey/SetStyle/SetText` 都是已有或 Task 7 加的 API。`SetStyle` 设 absolute + top 让 slot 定位到真实 item 位置。

- [ ] **Step 4: 不等高 driver 逻辑**

不等高与等高差异：item_sizes 是 Vec<float>（每 item 不同）+ 可见区间累加搜索 + slot top = sum + 尺寸补偿。在 VirtualListDriver 加 `bool _variableHeight` 分支：

```csharp
    // 不等高：item_sizes 缓存，初始用默认 size 估算，渲染后实测修正 + 尺寸补偿。
    readonly float[] _itemSizes;  // 不等高用
    float _defaultSize;

    // 不等高可见区间：累加搜索（从 sy 找首个 pos>sy 的 item）。
    int FindFirstVisible(float sy)
    {
        float acc = 0f;
        for (int i = 0; i < _itemCount; i++)
        {
            float sz = _itemSizes[i];
            if (acc + sz > sy) return i;
            acc += sz;
        }
        return (int)_itemCount - 1;
    }

    // 不等高 content_size = sum(itemSizes)。
    void RecalcContentSize()
    {
        float total = 0f;
        for (int i = 0; i < _itemCount; i++) total += _itemSizes[i];
        _stage.SetContentSize(_listContainer, 0, total);
    }

    // slot 渲染后实测 size 修正（不等高尺寸补偿）。
    void MeasureAndUpdateSlot(uint slotNodeId, uint itemIndex)
    {
        var r = _stage.GetNodeLayoutRect(slotNodeId);
        if (r.h > 0 && Math.Abs(r.h - _itemSizes[itemIndex]) > 0.1f)
        {
            float oldSize = _itemSizes[itemIndex];
            _itemSizes[itemIndex] = r.h;
            // 尺寸补偿：若该 item 在 scroll_pos 上方，同步偏移 scroll_pos 防跳动。
            var (sx, sy) = _stage.GetScrollPos(_listContainer);
            float itemTop = 0f;
            for (int i = 0; i < itemIndex; i++) itemTop += _itemSizes[i];
            if (itemTop < sy)
            {
                float delta = r.h - oldSize;
                _stage.SetScrollPos(_listContainer, sx, sy + delta, false);
            }
            RecalcContentSize();
        }
    }
```

SyncSlots 不等高分支：用 FindFirstVisible + 累加算 last + slot top = sum(itemSizes[0..idx]) + 调 MeasureAndUpdateSlot。
