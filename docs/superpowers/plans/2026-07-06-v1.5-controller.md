# v1.5 Controller (Pure-CSS Path) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver v1.5 Controller — `data-controller`/`data-page` state machines driving CSS attribute-selector cascade, plus standard CSS `transition` animation — so tab dialogs/page-switch UIs work with AI-predictable, Chromium-faithful HTML/CSS.

**Architecture:** Controller is a thin state-machine layer riding the existing every-frame `rematch_pseudo_classes` cascade. `[data-page]` attribute selectors query a `HashMap<NodeId, Controller>` registry during matching (no attribute writeback). `transition` writes through the existing `AnimTable` override layer via `TweenManager`. The big new ground is **attribute-selector parsing/matching** (currently zero implementation despite fence.md claiming support).

**Tech Stack:** Rust edition 2021 (loomgui_core / loomgui_pkg / loomgui_ffi_c), taffy 0.5, csbindgen 1, Unity 6.5 URP (C#), instasnap/snapshot tests via insta.

## Spec Calibration Notes

(Where this plan refines the spec after code investigation. All consistent with the spec's "implement to real constraints" caveat.)

1. **formatVersion is 12, not 8** → bump **12→13** (spec §5 corrected). No migrator exists; convention is MIN==MAX, reject+repackage.
2. **`mount_node` stored as `mount_node_idx: u32`** (component-local index, like `parent_idx`), remapped via `id_map` in `instantiate`.
3. **`AnimTable` IS the runtime_overrides layer** — already exists (`scene/node.rs`). `transition` writes through it via `TweenManager`; no new layer.
4. **`TweenProp` has 6 variants only**: Opacity/Translate/Scale/Rotation/BgColor/TextColor. `transition` animates only these; layout prop changes (display/width) snap. No transform_dirty/layout_dirty (doc-only).
5. **Pull-mode events only**: drop `register_changed_callback`; use `borrow_controller_changed_events` + `get_selected_index` polling.
6. **`extract_dynamic_rules` criterion extends**: a rule is dynamic if it has a pseudo-class **OR an attribute selector** (else `[data-page]` rules bake into base_style).
7. **First-cascade instant**: transition must not animate the initial cascade (node appearing with its dynamic style). Guard with a per-node `cascaded_once: bool`.

The current token loop (`selector.rs:100-110`) breaks tokens on `.`/`#`/`:`. Restructure to detect `[` … `]` spans. Replace the tokenization section inside the `for (text, comb) in &parts` loop (the `while idx < bytes.len()` block, ~line 100-111) with a version that, upon seeing `[`, scans to the matching `]` and parses `attr`, `attr="val"`, or `attr='val'`:

```rust
        // Tokenize: tag/class/id via ./#/:, plus [attr] / [attr="val"] spans.
        // CSS ident chars legal in attr name; = and quotes inside [] handled here.
        let bytes = text.as_bytes();
        let mut idx = 0;
        let mut kind = 't';
        let mut cur = String::new();
        let mut attrs: Vec<crate::style::dynamic::AttrSelector> = Vec::new();
        let push_token = |kind: char, val: &str,
                          tag: &mut Option<String>,
                          classes: &mut Vec<String>,
                          id: &mut Option<String>| {
            if val.is_empty() { return; }
            match kind {
                't' => *tag = Some(val.to_string()),
                '.' => classes.push(val.to_string()),
                '#' => *id = Some(val.to_string()),
                _ => {}
            }
        };
        while idx < bytes.len() {
            let c = bytes[idx] as char;
            if c == '[' {
                // flush current token, then scan to ']'
                push_token(kind, &cur, &mut tag, &mut classes, &mut id);
                cur.clear();
                let close = bytes[idx..].iter().position(|&b| b == b']')
                    .expect("parse layer guarantees balanced [] (or we treat malformed as no-match)");
                let inner = &text[idx + 1 .. idx + close];
                attrs.push(parse_attr_inner(inner));
                idx += close + 1;
                continue;
            }
            if c == '.' || c == '#' || c == ':' {
                push_token(kind, &cur, &mut tag, &mut classes, &mut id);
                cur.clear();
                kind = c;
            } else {
                cur.push(c);
            }
            idx += 1;
        }
        push_token(kind, &cur, &mut tag, &mut classes, &mut id);
```

Add the helper `parse_attr_inner` above `parse_selector`:

```rust
/// 解析 `[...]` 内部：`attr`、`attr="val"`、`attr='val'`。非相等形式（~= 等）围栏外，
/// 返 Exists（保守降级；围栏外值静默忽略）。attr 名小写归一（HTML 大小写不敏感）。
fn parse_attr_inner(inner: &str) -> crate::style::dynamic::AttrSelector {
    use crate::style::dynamic::{AttrOp, AttrSelector};
    let inner = inner.trim();
    if let Some((name, val)) = inner.split_once('=') {
        let name = name.trim().to_lowercase();
        let mut v = val.trim();
        if (v.starts_with('"') && v.ends_with('"'))
            || (v.starts_with('\'') && v.ends_with('\''))
        {
            v = &v[1..v.len() - 1];
        }
        AttrSelector { name, op: AttrOp::Eq, value: Some(v.to_string()) }
    } else {
        AttrSelector { name: inner.to_lowercase(), op: AttrOp::Exists, value: None }
    }
}
```

```rust
fn compound_matches_with_state(c: &Compound, node_id: NodeId, scene: &Scene) -> bool {
    // [data-page="N"] 是状态查询：从 node 向上找最近的 data_controller 祖先，
    // 查其 Controller.selected_index 字面比 N（CSS 就近原则，内层 controller 优先）。
    for a in &c.attrs {
        if a.name == "data-page" {
            if !matches!(a.op, AttrOp::Eq) { return false; } // [data-page] 只认 =
            let want = match &a.value { Some(v) => v.as_str(), None => return false };
            let governing = find_governing_controller(node_id, scene);
            let matched = match governing {
                Some((_, selected)) => selected.to_string() == want,
                None => false,
            };
            if !matched { return false; }
        }
    }
    // 伪类状态门 + 字面 attr 匹配
    let node = scene.get(node_id).expect("live node");
    if c.pseudo_hover && !node.hovered { return false; }
    if c.pseudo_active && !node.active { return false; }
    if c.pseudo_disabled && !node.disabled { return false; }
    if c.pseudo_focus && !node.focused { return false; }
    compound_matches_node(c, node) // data-controller 字面匹配在此处理（C1）
}
```

Add helper `find_governing_controller`:

```rust
/// 从 node（含自身）向上找最近带 data_controller 的祖先 → 返 (mount_node_id, selected_index)。
/// 无挂载祖先 / registry 无该 Controller → None。
fn find_governing_controller(start: NodeId, scene: &Scene) -> Option<(NodeId, i32)> {
    let mut cur = Some(start);
    while let Some nid) = cur {
        if let Some(n) = scene.get(nid) {
            if n.data_controller.is_some() {
                if let Some(ctrl) = scene.controllers.get(&nid) {
                    return Some((nid, ctrl.selected_index));
                }
                // data_controller 声明了但 registry 没条目（加载未完成/孤儿）→ 该祖先不算，继续上
            }
            cur = n.parent;
        } else {
            break;
        }
    }
    None
}
```

fn parse_transition(value: &str) -> Option<crate::style::resolved::TransitionSpec> {
    use crate::style::resolved::TransitionSpec;
    use crate::tween::{Ease, TweenProp};
    // 简化解析：空格切 token。第 1 个 = 属性名；含 's' 的 = duration/delay；
    // 其余 = ease 关键字。容错：缺省补默认（dur 0s, ease linear, delay 0s）。
    let tokens: Vec<&str> = value.split_whitespace().collect();
    if tokens.is_empty() { return None; }
    let mut prop = None;
    let mut duration = 0.0f32;
    let mut delay = 0.0f32;
    let mut ease = Ease::Linear;
    for t in tokens {
        if t == "all" { prop = None; }
        else if t == "opacity" { prop = Some(TweenProp::Opacity); }
        else if t == "color" { prop = Some(TweenProp::TextColor); }
        else if t == "background-color" { prop = Some(TweenProp::BgColor); }
        else if t.ends_with('s') {
            let n = t.trim_end_matches('s').parse::<f32>().unwrap_or(0.0);
            if duration == 0.0 { duration = n; } else { delay = n; }
        } else {
            // ease keyword
            ease = match t { "linear" => Ease::Linear, "ease-in" => Ease::SineIn,
                "ease-out" => Ease::SineOut, "ease-in-out" => Ease::SineInOut,
                _ => Ease::Linear };
        }
    }
    Some(TransitionSpec { prop, duration, ease, delay })
}

/// 比较 old/new 的可动画通道；变化的（且 transition 声明覆盖该通道）推入 pending_transitions。
fn emit_transition_requests(
    scene: &mut Scene, node: NodeId, ts: TransitionSpec,
    old: &ResolvedStyle, new: &ResolvedStyle,
) {
    use crate::tween::{TweenProp, TransitionRequest};
    let wants = |p: TweenProp| matches!(ts.prop, None) || matches!(ts.prop, Some(q) if q == p);
    let anim = scene.anim.get(node); // mid-flight override 作 start（无则 old cascade 值）
    // background-color: Option<[f32;4]>
    if wants(TweenProp::BgColor) {
        let a = old.background_color.unwrap_or([0.0;4]);
        let b = new.background_color.unwrap_or([0.0;4]);
        if a != b {
            let start = anim.and_then(|x| x.bg_color).unwrap_or(a);
            scene.pending_transitions.push(TransitionRequest {
                node, prop: TweenProp::BgColor, start: start, end: b,
                ease: ts.ease, delay: ts.delay, duration: ts.duration,
            });
        }
    }
    if wants(TweenProp::TextColor) {
        let a = old.color; let b = new.color;
        if a != b {
            let start = anim.and_then(|x| x.text_color).unwrap_or(a);
            scene.pending_transitions.push(TransitionRequest {
                node, prop: TweenProp::TextColor, start: start, end: b,
                ease: ts.ease, delay: ts.delay, duration: ts.duration,
            });
        }
    }
    if wants(TweenProp::Opacity) {
        if (old.opacity - new.opacity).abs() > 1e-6 {
            let start = anim.and_then(|x| x.opacity).unwrap_or(old.opacity);
            scene.pending_transitions.push(TransitionRequest {
                node, prop: TweenProp::Opacity, start: [start,0.0,0.0,0.0], end: [new.opacity,0.0,0.0,0.0],
                ease: ts.ease, delay: ts.delay, duration: ts.duration,
            });
        }
    }
    // translate/scale/rotation 需分解 transform 矩阵——本期不做（围栏 transition 不含 transform）。
}
