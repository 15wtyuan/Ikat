# v1.7 Rich Text Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 LoomGUI 加富文本——一个 RichText 叶子 NodeKind，内部跑简化 inline flow（多样式 run + 行内图 + 超链接 + 装饰线）；DSL 层 AI 写 `<div style="display:block">...inline HTML...</div>`，打包器 desugar 成 flex div + rich 叶（保 div=flex 铁律）。

**Architecture:** 复用 v1.6 地基（核心 GlyphAtlas、text-as-Mesh `program=1`、per-vertex color、blob v10、Unity SyncFontAtlas）。新增：RichRun 模型 + 子集 markup 解析器（dedicated，runtime 可用）+ 简化 inline flow（measure 纯函数算尺寸、build 产 mesh quad）+ `display:block` desugar pass（打包器）+ `set_rich_text` 动态 API + `rich_link_at` 命中查询 FFI。扩展 `GlyphRun` 携带 per-run font_id/color/weight/style/deco/link_id，统一 plain 与 rich 走同一条 measure→build 链。blob v10 不 bump；pkg 格式 13→14（新 NodeKind 变体）。

**Tech Stack:** Rust core（ttf-parser 0.20 + ab_glyph_rasterizer 0.1 + etagere 0.3 + unicode-linebreak 0.1，均 v1.6 已引入，无新依赖）+ csbindgen FFI + Unity 6.5 C#（URP）。本机唯一编码机（cargo 编 .dll + 重打 pkg + commit + push），家里机 PlayMode 验收。

**Spec:** `docs/superpowers/specs/2026-07-07-v1.7-rich-text-design.md`（权威）。RmlUi/fgui 对标取证见该 spec §13 + 三份深读报告。

## Global Constraints

- **measure 纯函数**（spec §2.5）：光栅 + atlas ensure 是 build 期副作用，**不进 measure**（taffy MeasureFunc 反复调，须零副作用、廉价）。runs 在 set_rich_text / 场景加载时解析缓存；measure 只读 runs 算尺寸。
- **FFI 入口绝不 panic**（坑 102）：`set_rich_text` / `rich_link_at` 用 `match None → 返 -1/0`、null 句柄早返、`from_utf8(..).unwrap_or("")`。cdylib 里 `.unwrap()`/`.expect()` 会 non-unwinding abort 拖垮宿主。
- **FFI 边界 enum 必须 `#[repr(uN)]`**（坑 34）；新增/改 FFI struct 须同步手补 C# 镜像（坑 35，csbindgen 不为 `#[repr(C)]` struct 生成 stub）。
- **dll 闭环**（坑 10/100）：改 Rust FFI 后 `cargo build -p loomgui_ffi_c --release` + 拷 dll + `nm/findstr` 查新符号 + `md5sum` 核对入库 dll。拷 dll 时 Unity 须关着。
- **改 parse-time 逻辑必重打 pkg**（坑 66）：desugar 是打包期变换，改 desugar/mapping/dom 后须 `cargo run -p loomgui_pkg` 重打 pkg（html/css 未变也要）。纯 runtime（measure/build/FFI）改 .dll 即可。
- **PKG_FORMAT_VERSION bump 13→14**（asset/mod.rs:23）：NodeKind 新增 RichText 变体破坏序列化兼容。家里机须拉新 .dll + 重打 pkg 同步，否则旧 pkg 反序列化炸。
- **fence_contract 门**（CLAUDE.md）：改 apply_decl / FENCE_TAGS / desugar 后必跑 `cargo test -p loomgui_core fence_contract`。
- **坑号只进 docs/pitfalls.md，不进代码注释**（CLAUDE.md）。代码注释上线品质：自包含、说 WHY、不引用内部编号。
- **API 适配方法论**（CLAUDE.md）：ttf-parser 0.20 font metrics（ascender/descender/underline_metrics 等）签名以 registry src 为准（`~/.cargo/registry/src/ttf-parser-0.20*/src/`），遇编译错按实际 src 调，勿硬改依赖版本。
- **两台机串行**：本机 build+commit+push；家里机 PlayMode 逐项验收（坑 131-133 教训：SDD 单测绿 ≠ 集成对，CSS 语义集成只在 PlayMode 显现）。
- **当前分支**：`feat/v1.7-rich-text`（spec commit `e8e1613`）。

//! 富文本（v1.7）：run 模型 + 子集 markup 解析器 + 简化 inline flow。

//! per-run 多色多字号（v1.6 atlas key 已含 font_id/size_px，per-run color 走 per-vertex）。
//! 简化模型：扁平 run 流 + 单遍断行 + max-baseline-per-line（非完整 CSS IFC）。

/// 加粗。MVP 合成（build 期几何加粗，非字体变体）。
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, serde::Serialize, serde::Deserialize)]
#[repr(u8)]
pub enum RichWeight {
    #[default]
    Normal = 0,
    Bold = 1,
}

/// 斜体。MVP 合成（build 期 quad skew）。
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, serde::Serialize, serde::Deserialize)]
#[repr(u8)]
pub enum RichStyle {
    #[default]
    Normal = 0,
    Italic = 1,
}

/// 装饰线（下划线/删除线，build 期纯 quad）。
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, serde::Serialize, serde::Deserialize)]
pub struct RichDeco {
    pub underline: bool,
    pub strike: bool,
}

/// 行内图垂直对齐（简化：baseline 默认底边贴基线）。
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, serde::Serialize, serde::Deserialize)]
#[repr(u8)]
pub enum RichVAlign {
    #[default]
    Baseline = 0,
    Middle = 1,
    Top = 2,
    Bottom = 3,
}

/// 一段同样式富文本。per-glyph 多色靠多个相邻 run（非 per-glyph 字段）。
#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct RichRun {
    pub kind: RichKind,
    pub color: [f32; 4],
    pub font_id: u32,
    pub size_px: u16,
    pub weight: RichWeight,
    pub style: RichStyle,
    pub deco: RichDeco,
    /// 属于某超链接（<a> 内）；命中查 fragment 矩形时返此 id。None=非链接。
    pub link_id: Option<u32>,
}

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub enum RichKind {
    Text { text: String },
    /// 行内图（含 emoji-图片）：复用 image_path 机制，进 image atlas（非 glyph atlas）。
    Image {
        src: String,
        w: f32,
        h: f32,
        valign: RichVAlign,
    },
}

impl RichRun {
    /// 纯文本 run 的便捷构造（继承 base 色/字体）。
    pub fn text(text: impl Into<String>, color: [f32; 4], font_id: u32, size_px: u16) -> Self {
        RichRun {
            kind: RichKind::Text { text: text.into() },
            color,
            font_id,
            size_px,
            weight: RichWeight::Normal,
            style: RichStyle::Normal,
            deco: RichDeco::default(),
            link_id: None,
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn rich_run_serde_roundtrip() {
        let r = RichRun {
            kind: RichKind::Text { text: "hi".into() },
            color: [1.0, 0.0, 0.0, 1.0],
            font_id: 2,
            size_px: 24,

            style: RichStyle::Italic,
            deco: RichDeco { underline: true, strike: false },
            link_id: Some(7),

        assert_eq!(back.font_id, 2);
        assert_eq!(back.weight, RichWeight::Bold);
        assert_eq!(back.link_id, Some(7));
    }
}

/// 富文本 base 样式（caller 从节点 ResolvedStyle 转换来）。
#[derive(Debug, Clone, Copy)]
pub struct RichBaseStyle {
    pub color: [f32; 4],
    pub font_size: f32, // px
    pub weight: RichWeight,
    pub style: RichStyle,
    pub deco: RichDeco,
}

/// 解析富内容 markup 子集 → flatten 后的 run 序列。
///
/// 子集标签：`b/strong`(粗) `i/em`(斜) `u`(下划线) `s/del/strike`(删除线)
/// `span style="..."`(内联样式) `a href="..."`(链接，link_id=1-based 文档序)
/// `img src=.. width=.. height=.. vertical-align=..` `br`(换行)。
/// 嵌套标签 flatten：每个 text run 携完整 effective style（栈式 cascade）。
/// 未闭合/未知标签 → Err（静态打包期硬挡；动态 set_rich_text 也 Err→FFI 返 -1，
/// chat 输入不可信，调用方应保证 markup 合法或自行清洗）。
pub fn parse_rich_markup(
    markup: &str,
    base: RichBaseStyle,
    default_font_id: u32,
) -> Result<Vec<RichRun>, String> {
    let mut runs: Vec<RichRun> = Vec::new();
    let mut link_next: u32 = 1;
    // 栈底 = base；每个 open tag push 一个 Eff clone。
    let bottom = Eff {
        color: base.color,
        size_px: base.font_size.round().max(1.0) as u16,
        weight: base.weight,
        style: base.style,
        deco: base.deco,
        link_id: None,
    };
    let mut stack: Vec<Eff> = vec![bottom];
    let mut tag_stack: Vec<&str> = vec![""]; // 平行跟踪标签名（close 校验用）

    let bytes = markup.as_bytes();
    let mut i = 0;
    let mut text_buf = String::new();
    while i < bytes.len() {
        let c = bytes[i];
        if c == b'<' {
            // flush 前置文本
            if !text_buf.is_empty() {
                emit_text(&mut runs, &text_buf, *stack.last().unwrap(), default_font_id);
                text_buf.clear();
            }
            // 读 tag：找到下一个 '>'
            let end = match markup[i..].find('>') {
                Some(e) => i + e,
                None => return Err("unclosed tag (missing '>')".into()),
            };
            let tag_inner = &markup[i + 1..end];
            i = end + 1;
            if tag_inner.starts_with('/') {
                // close tag
                let name = tag_inner[1..].trim();
                if stack.len() <= 1 {
                    return Err(format!("unexpected </{name}>"));
                }
                let expected = *tag_stack.last().unwrap();
                if expected != name {
                    return Err(format!("mismatched close: <{expected}> vs </{name}>"));
                }
                stack.pop();
                tag_stack.pop();
            } else {
                let (name, attrs) = split_tag(tag_inner);
                let self_closing = name.ends_with('/');
                let name = name.trim_end_matches('/').trim();
                let cur = *stack.last().unwrap();
                match name {
                    "b" | "strong" => {
                        let mut e = cur; e.weight = RichWeight::Bold;
                        push_open(&mut stack, &mut tag_stack, e, "b");
                    }
                    "i" | "em" => {
                        let mut e = cur; e.style = RichStyle::Italic;
                        push_open(&mut stack, &mut tag_stack, e, "i");
                    }
                    "u" => {
                        let mut e = cur; e.deco.underline = true;
                        push_open(&mut stack, &mut tag_stack, e, "u");
                    }
                    "s" | "del" | "strike" => {
                        let mut e = cur; e.deco.strike = true;
                        push_open(&mut stack, &mut tag_stack, e, "s");
                    }
                    "span" => {
                        let mut e = cur;
                        if let Some(style_val) = get_attr(attrs, "style") {
                            apply_inline_style(&mut e, style_val);
                        }
                        push_open(&mut stack, &mut tag_stack, e, "span");
                    }
                    "a" => {
                        let id = link_next; link_next += 1;
                        let mut e = cur; e.link_id = Some(id);
                        push_open(&mut stack, &mut tag_stack, e, "a");
                    }
                    "img" => {
                        let src = get_attr(attrs, "src").unwrap_or("").to_string();
                        let w = get_attr(attrs, "width").and_then(parse_px).unwrap_or(0.0);
                        let h = get_attr(attrs, "height").and_then(parse_px).unwrap_or(0.0);
                        let valign = get_attr(attrs, "vertical-align")
                            .map(parse_valign).unwrap_or_default();
                        runs.push(RichRun {
                            kind: RichKind::Image { src, w, h, valign },
                            color: cur.color, font_id: default_font_id,
                            size_px: cur.size_px, weight: cur.weight, style: cur.style,
                            deco: cur.deco, link_id: cur.link_id,
                        });
                        // img 自闭合，不 push 栈
                    }
                    "br" => {
                        // 换行：插一个只含 "\n" 的 text run（measure 据此断行）
                        emit_text(&mut runs, "\n", *stack.last().unwrap(), default_font_id);
                    }
                    other => return Err(format!("unsupported rich tag: <{other}>")),
                }
                let _ = self_closing; // 各分支已处理（img/br 自闭合，其余需显式 close）
            }
        } else {
            // 累积文本（HTML 空白折叠：连续空白压成单空格）
            let ch = char::from_u32(c as u32).unwrap_or(' ');
            if ch.is_whitespace() {
                if !text_buf.ends_with(' ') { text_buf.push(' '); }
            } else {
                // 处理 HTML 实体（最小：&lt; &gt; &amp; &nbsp;）——遇 & 尝试解析
                if ch == '&' {
                    if let Some((entity, next)) = parse_entity(&markup[i..]) {
                        text_buf.push_str(&entity);
                        i = next;
                        continue;
                    }
                }
                text_buf.push(ch);
            }
            i += 1;
        }
    }
    // flush 末尾文本
    if !text_buf.is_empty() {
        emit_text(&mut runs, &text_buf, *stack.last().unwrap(), default_font_id);
    }
    if stack.len() != 1 {
        return Err(format!("unclosed tag: <{}>", tag_stack.last().unwrap()));
    }
    Ok(runs)
}

#[derive(Clone, Copy)]
struct Eff {
    color: [f32; 4],
    size_px: u16,
    weight: RichWeight,
    style: RichStyle,
    deco: RichDeco,
    link_id: Option<u32>,
}

fn push_open<'a>(stack: &mut Vec<Eff>, tag_stack: &mut Vec<&'a str>, e: Eff, name: &'a str) {
    stack.push(e);
    tag_stack.push(name);
}

fn emit_text(runs: &mut Vec<RichRun>, text: &str, eff: Eff, font_id: u32) {
    if text.is_empty() { return; }
    runs.push(RichRun {
        kind: RichKind::Text { text: text.into() },
        color: eff.color, font_id, size_px: eff.size_px,
        weight: eff.weight, style: eff.style, deco: eff.deco, link_id: eff.link_id,
    });
}

fn split_tag(inner: &str) -> (&str, &str) {
    // 第一个空格前是 tag 名，之后是 attrs
    match inner.find(char::is_whitespace) {
        Some(p) => (&inner[..p], inner[p..].trim()),
        None => (inner, ""),
    }
}

fn get_attr<'a>(attrs: &'a str, name: &str) -> Option<&'a str> {
    let needle = format!("{name}=");
    let idx = attrs.find(&needle)?;
    let rest = &attrs[idx + needle.len()..];
    let quote = rest.chars().next()?;
    if quote == '"' || quote == '\'' {
        let val_start = 1;
        let val_end = rest[1..].find(quote)?;
        Some(&rest[val_start..1 + val_end])
    } else {
        // 无引号：读到空白
        let end = rest.find(char::is_whitespace).unwrap_or(rest.len());
        Some(&rest[..end])
    }
}

fn parse_px(val: &str) -> Option<f32> {
    let v = val.trim().trim_end_matches("px").trim();
    v.parse::<f32>().ok()
}

fn parse_valign(val: &str) -> RichVAlign {
    match val.trim() {
        "middle" => RichVAlign::Middle,
        "top" => RichVAlign::Top,
        "bottom" => RichVAlign::Bottom,
        _ => RichVAlign::Baseline,
    }
}

fn apply_inline_style(eff: &mut Eff, style_attr: &str) {
    for decl in style_attr.split(';') {
        let mut parts = decl.splitn(2, ':');
        let prop = parts.next().unwrap_or("").trim();
        let val = parts.next().unwrap_or("").trim();
        if prop.is_empty() { continue; }
        match prop {
            "color" => { if let Some(c) = parse_color_hex(val) { eff.color = c; } }
            "font-size" => { if let Some(px) = parse_px(val) { eff.size_px = px.round().max(1.0) as u16; } }
            "font-weight" => match val {
                "bold" | "700" | "800" | "900" => eff.weight = RichWeight::Bold,
                "normal" | "400" | "300" | "200" | "100" => eff.weight = RichWeight::Normal,
                _ => {}
            },
            "font-style" => match val {
                "italic" | "oblique" => eff.style = RichStyle::Italic,
                "normal" => eff.style = RichStyle::Normal,
                _ => {}
            },
            "text-decoration" => {
                if val.contains("underline") { eff.deco.underline = true; }
                if val.contains("line-through") { eff.deco.strike = true; }
            }
            _ => {} // unsupported inline prop 忽略（围栏哲学）
        }
    }
}

/// 最小 HTML 实体解析。返回 (解码串, 消费后的字节偏移)。
fn parse_entity(s: &str) -> Option<(String, usize)> {
    let end = s.find(';')?;
    let ent = &s[..=end]; // 含 ; 
    let mapped = match ent {
        "&lt;" => "<",
        "&gt;" => ">",
        "&amp;" => "&",
        "&nbsp;" | "&#160;" => " ",
        "&quot;" => "\"",
        "&apos;" => "'",
        _ => return None,
    };
    Some((mapped.into(), ent.len()))
}

/// 解析 #rgb / #rrggbb / #rrggbbaa 颜色 → [r,g,b,a] 归一化。
/// 若 LoomGUI 已有共享颜色解析器（grep `fn parse_color` in style/），改用之。
fn parse_color_hex(val: &str) -> Option<[f32; 4]> {
    let v = val.trim();
    if !v.starts_with('#') { return None; }
    let h = &v[1..];
    let (r, g, b, a) = match h.len() {
        3 => {
            let r = u8::from_str_radix(&h[0..1].repeat(2), 16).ok()?;
            let g = u8::from_str_radix(&h[1..2].repeat(2), 16).ok()?;
            let b = u8::from_str_radix(&h[2..3].repeat(2), 16).ok()?;
            (r, g, b, 255u8)
        }
        6 => {
            let r = u8::from_str_radix(&h[0..2], 16).ok()?;
            let g = u8::from_str_radix(&h[2..4], 16).ok()?;
            let b = u8::from_str_radix(&h[4..6], 16).ok()?;
            (r, g, b, 255u8)
        }
        8 => {
            let r = u8::from_str_radix(&h[0..2], 16).ok()?;
            let g = u8::from_str_radix(&h[2..4], 16).ok()?;
            let b = u8::from_str_radix(&h[4..6], 16).ok()?;
            let a = u8::from_str_radix(&h[6..8], 16).ok()?;
            (r, g, b, a)
        }
        _ => return None,
    };
    Some([r as f32 / 255.0, g as f32 / 255.0, b as f32 / 255.0, a as f32 / 255.0])
}

/// 1. 扁平 token 流：每 run 的 text 切成 token（CJK 逐字 / Latin 逐词），token 携 run 样式。
/// 2. 贪心断行：token 累加超 max_width → 开新行；"\n" 强制换行。
/// 3. 每行 baseline = max(该行 run 的 ascent)；行高 = max(strut, max_ascent + max_descent)。
/// 4. 定位：pen x 累加 advance + kern；glyph y = line.baseline。
///
/// 纯函数：不光栅、不读 atlas（atlas ensure 在 build 期）。可被 taffy 反复调。
pub fn measure_rich_text(
    runs: &[RichRun],
    max_width: Option<f32>,
    base_line_height: f32,
    font: &Font,
    default_font_id: u32,
) -> TextLayout {
    let ascent = font.ascent();
    let descent = font.descent();
    let line_gap = font.line_gap();
    let units = font.face.units_per_em().max(1) as f32;

    // 1. 扁平 token 流（token = 子串 + 所属 run 索引 + 宽度）
    struct Tok<'a> { text: &'a str, run_idx: usize, w: f32, is_break: bool }
    let mut tokens: Vec<Tok> = Vec::new();
    for (ri, r) in runs.iter().enumerate() {
        match &r.kind {
            RichKind::Text { text } => {
                if text == "\n" { tokens.push(Tok { text: "\n", run_idx: ri, w: 0.0, is_break: true }); continue; }
                let scale = r.size_px as f32 / units;
                // CJK 逐字、Latin 逐词（空白分词，简化：按空白切词，非空白段再按字符判 CJK）
                for word in text.split(' ') {
                    if word.is_empty() { continue; }
                    // CJK 拆单字（每字一 token），Latin 整词一 token
                    if word.chars().any(is_cjk) {
                        for ch in word.chars() {
                            let w = char_advance(font, ch, scale) * scale;
                            tokens.push(Tok { text: unsafe { /* 单字子串 */ word_ref(word, ch) }, run_idx: ri, w, is_break: false });
                        }
                    } else {
                        let w = str_advance(font, word, scale);
                        tokens.push(Tok { text: word, run_idx: ri, w, is_break: false });
                    }
                }
            }
            RichKind::Image { w, .. } => {
                tokens.push(Tok { text: "", run_idx: ri, w: *w, is_break: false });
            }
        }
    }

    // 2. 贪心断行
    let mut lines: Vec<Vec<usize>> = vec![Vec::new()]; // 每行 = token 索引列表
    let mut cur_w = 0.0f32;
    for (ti, tok) in tokens.iter().enumerate() {
        if tok.is_break {
            lines.push(Vec::new()); cur_w = 0.0; continue;
        }
        let fits = max_width.map_or(true, |mw| cur_w + tok.w <= mw || lines.last().unwrap().is_empty());
        if !fits {
            lines.push(Vec::new()); cur_w = 0.0;
        }
        lines.last_mut().unwrap().push(ti);
        cur_w += tok.w;
    }

    // 3+4. 每行 baseline/高度 + 字形定位
    let mut out_lines: Vec<Line> = Vec::new();
    let mut y = 0.0f32;
    let kern = |l: ttf_parser::GlyphId, r: ttf_parser::GlyphId| -> f32 {
        kerning_value(font, l, r) // 复用 measure_text 的 kern 闭包逻辑（见 Step 4 抽出）
    };
    for line_toks in &lines {
        if line_toks.is_empty() { // 空行（如 <br><br> 间）仍占行高
            let h = strut_height(base_line_height, 24.0, ascent, descent, line_gap);
            out_lines.push(Line { y, height: h, baseline: ascent.max(0.0), width: 0.0, runs: Vec::new() });
            y += h; continue;
        }
        // 该行 max 字号决定 baseline/strut
        let line_size = line_toks.iter()
            .map(|&ti| runs[tokens[ti].run_idx].size_px as f32).fold(0.0f32, f32::max).max(1.0);
        let scale = line_size / units;
        let line_ascent = ascent * scale;
        let line_descent = (-descent) * scale; // descent 负
        let h = strut_height(base_line_height, line_size, ascent, descent, line_gap);
        let baseline = line_ascent; // 顶到 baseline
        // 按 run 分组生成 GlyphRun
        let mut runs_out: Vec<GlyphRun> = Vec::new();
        let mut pen_x = 0.0f32;
        let mut prev_gid: Option<ttf_parser::GlyphId> = None;
        for &ti in line_toks {
            let r = &runs[tokens[ti].run_idx];
            match &r.kind {
                RichKind::Text { text } => {
                    let mut glyphs: Vec<Glyph> = Vec::new();
                    let r_scale = r.size_px as f32 / units;
                    for ch in text.chars() {
                        let gid_opt = font.face.glyph_index(ch);
                        let adv = glyph_advance(font, gid_opt, r_scale) + prev_gid.and_then(|p| kern(p, gid_opt.unwrap_or(ttf_parser::GlyphId(0)))).unwrap_or(0.0);
                        let gid = gid_opt.map(|g| g.0).unwrap_or(0);
                        let bearing_x = font.face.glyph_bounding_box(ttf_parser::GlyphId(gid)).map(|b| b.x_min as f32 * r_scale).unwrap_or(0.0);
                        let bearing_y = font.face.glyph_bounding_box(ttf_parser::GlyphId(gid)).map(|b| b.y_max as f32 * r_scale).unwrap_or(0.0);
                        glyphs.push(Glyph { glyph_id: gid, codepoint: ch as u32, x: pen_x, y: 0.0, bearing_x, bearing_y });
                        pen_x += adv;
                        prev_gid = gid_opt;
                    }
                    runs_out.push(GlyphRun {
                        font_size: r.size_px as f32, font_id: r.font_id, color: r.color,
                        weight: r.weight, style: r.style, deco: r.deco, link_id: r.link_id, glyphs,
                    });
                }
                RichKind::Image { w, .. } => {
                    // 图占位：无 glyph（build 期另产 image quad）；占宽
                    pen_x += w;
                    // 仍 push 一个空 glyph 的 run 携带 image 标记？build 按原图 run 处理。
                    // 简化：image 不进 GlyphRun（build 遍历原始 runs 产图 quad，见 T8）。
                    let _ = r;
                }
            }
        }
        let width = pen_x;
        out_lines.push(Line { y, height: h, baseline, width, runs: runs_out });
        y += h;
    }

    let text_width = out_lines.iter().map(|l| l.width).fold(0.0f32, f32::max);
    let text_height = y;
    TextLayout { text_width, text_height, lines: out_lines }
}

/// CJK 判定（简化：常见 CJK 区间）。断行用——CJK 每字可换行。
fn is_cjk(ch: char) -> bool {
    let c = ch as u32;
    (0x4E00..=0x9FFF).contains(&c)       // CJK 统一
        || (0x3000..=0x303F).contains(&c) // CJK 标点
        || (0xFF00..=0xFFEF).contains(&c) // 全角
        || (0x3040..=0x30FF).contains(&c) // 假名
}

/// strut 半行距行高（搬 RmlUi GetStrut：line_height > 0 用倍数，否则 ascent-descent+gap）。
/// 取该行 max 字号作 size。
fn strut_height(line_height: f32, size: f32, ascent: f32, descent: f32, line_gap: f32) -> f32 {
    if line_height > 0.0 { size * line_height } else { ascent - descent + line_gap }
}
```

/// 把 TextLayout 每字形展成 quad mesh（per-page 分组）。per-run 色/font_id 从 GlyphRun 读。
/// 合成 bold（双绘 +1px x 偏移加粗）/italic（顶边右偏 0.3×高）。
fn build_text_mesh(
    layout: &crate::text::layout::TextLayout,
    atlas: &mut GlyphAtlas,
    font: &crate::text::layout::Font,
    default_font_id: u32,
) -> Vec<(u32, Vec<[f32; 2]>, Vec<[f32; 2]>, Vec<[f32; 4]>, Vec<u32>)> {
    use std::collections::BTreeMap;
    let mut pages: BTreeMap<u32, (Vec<[f32;2]>, Vec<[f32;2]>, Vec<[f32;4]>, Vec<u32>)> = BTreeMap::new();
    let face = &font.face;
    for line in &layout.lines {
        for run in &line.runs {
            let size_px = run.font_size.round().max(1.0) as u16;
            let italic_skew = if matches!(run.style, crate::text::rich::RichStyle::Italic) { 0.3 } else { 0.0 };
            let bold_offsets: &[f32] = if matches!(run.weight, crate::text::rich::RichWeight::Bold) { &[0.0, 1.0] } else { &[0.0] };
            for g in &run.glyphs {
                let key = GlyphKey { font_id: default_font_id, glyph_id: g.glyph_id, size_px, effect_sig: 0 };
                let r = atlas.ensure(face, key);
                for &boff in bold_offsets {
                    let left = g.x + g.bearing_x + boff;
                    let top = line.baseline + g.bearing_y;
                    let right = left + r.px_w as f32;
                    let bottom = top - r.px_h as f32;
                    // italic：顶边右偏（skew），底边不动。简化：top-left/top-right 加 skew×高度。
                    let skew_top = italic_skew * r.px_h as f32;
                    let (p, _) = pages.entry(r.page).or_insert_with(|| (Vec::new(), Vec::new(), Vec::new(), Vec::new()));
                    let base = p.0.len() as u32;
                    // 顶点序 BL, BR, TR, TL（与现有 text mesh 一致）
                    p.0.push([left, bottom]); p.0.push([right, bottom]);
                    p.0.push([right + skew_top, top]); p.0.push([left + skew_top, top]);
                    // UV V 翻转（与现有一致）：BL→(u0,v1), BR→(u1,v1), TR→(u1,v0), TL→(u0,v0)
                    p.1.push([r.u0, r.v1]); p.1.push([r.u1, r.v1]);
                    p.1.push([r.u1, r.v0]); p.1.push([r.u0, r.v0]);
                    for _ in 0..4 { p.2.push(run.color); }
                    p.3.extend_from_slice(&[base, base+1, base+2, base, base+2, base+3]);
                }
            }
        }
    }
    pages.into_iter().map(|(pg, (v,u,c,i))| (pg, v, u, c, i)).collect()
}
```

/// v1.7 desugar：inline display:block div 的 raw_rich → parse_rich_markup → runs，
/// 存进 ElementData 供 build_scene 产 NodeKind::RichText。同时执法 block div 拒 flex 属性。
fn desugar_block_divs(
    mut tree: loomgui_core::parse::dom::ElementTree,
    styles: Vec<loomgui_core::style::resolved::ResolvedStyle>,
) -> Result<(loomgui_core::parse::dom::ElementTree, Vec<loomgui_core::style::resolved::ResolvedStyle>), String> {
    use loomgui_core::style::resolved::DisplayMode;
    for (idx, data) in tree.nodes.iter_mut().enumerate() {
        let Some(raw) = data.raw_rich.as_ref() else { continue };
        // 守护栏（spec §4.2 第 3 条）：block div 拒 flex 属性
        let s = &styles[idx];
        if s.display_mode == DisplayMode::Block {
            check_no_flex_props(s).map_err(|e| format!("元素 <{}>: {e}", data.tag))?;
        }
        // base 样式从 styles[idx] 转 RichBaseStyle
        let base = loomgui_core::text::rich::RichBaseStyle {
            color: s.color,
            font_size: s.font_size,
            weight: loomgui_core::text::rich::RichWeight::Normal, // MVP：base 不带粗（<b> 才粗）
            style: loomgui_core::text::rich::RichStyle::Normal,
            deco: loomgui_core::text::rich::RichDeco::default(),
        };
        let runs = loomgui_core::text::rich::parse_rich_markup(raw, base, 0)?;
        // 标记本元素为 RichText：build_scene 据 raw_rich + runs 产 NodeKind::RichText。
        // ElementData 加 rich_runs 字段存解析结果（避免 build_scene 重 parse）。
        data.rich_runs = Some(runs);
    }
    Ok((tree, styles))
}

fn check_no_flex_props(s: &loomgui_core::style::resolved::ResolvedStyle) -> Result<(), String> {
    let ts = &s.taffy_style;
    if !ts.justify_content.is_default() { return Err("display:block 不支持 justify-content".into()); }
    if !ts.align_items.is_default() { return Err("display:block 不支持 align-items".into()); }
    if !ts.gap.is_default() { return Err("display:block 不支持 gap".into()); }
    // flex_direction/grow/order 类似检查（按 ResolvedStyle 实际字段）
    Ok(())
}
```

    /// 取一个 1×1 白像素槽（装饰线/纯色填充用）。首次调分配并填 255，其后命中缓存。
    pub fn ensure_solid(&mut self) -> GlyphRect {
        let key = GlyphKey { font_id: u32::MAX, glyph_id: u16::MAX, size_px: 1, effect_sig: u64::MAX };
        if let Some(r) = self.cache.get(&key) { return *r; }
        // 分配 1×1 + 填白
        let alloc = self.allocate(1, 1);
        let page = &mut self.pages[alloc.page as usize];
        page.pixels[alloc.px_y as usize * page.width as usize + alloc.px_x as usize] = 255;
        if !self.dirty.contains(&alloc.page) { self.dirty.push(alloc.page); }
        let uv = GlyphRect {
            page: alloc.page,
            u0: alloc.px_x as f32 / page.width as f32,
            v0: alloc.px_y as f32 / page.height as f32,
            u1: (alloc.px_x + 1) as f32 / page.width as f32,
            v1: (alloc.px_y + 1) as f32 / page.height as f32,
            px_w: 1, px_h: 1,
        };
        self.cache.insert(key, uv);
        uv
    }
```

/// pull 模式：Unity Click 命中节点级 AABB 后调本函数细分到 fragment。
pub fn rich_link_at(&self, node: NodeId, world_x: f32, world_y: f32) -> u32 {
    let scene = match &self.scene { Some(s) => s, None => return 0 };
    // 取节点 world_matrix 反变换到本地坐标
    let wm = scene.world_transform(node).unwrap_or(crate::transform::IDENTITY); // 复用 get_node_world_matrix 路径
    let (lx, ly) = crate::transform::inverse_transform_point(&wm, world_x, world_y);
    let n = match scene.get(node) { Some(n) => n, None => return 0 };
    if !matches!(n.kind, crate::scene::node::NodeKind::RichText { .. }) { return 0; }
    let frags = match scene.rich_fragments.get(n.id.index()).and_then(|f| f.as_ref()) { Some(f) => f, None => return 0 };
    for fr in frags {
        if world_x >= fr.x && world_x <= fr.x + fr.w && world_y >= fr.y && world_y <= fr.y + fr.h {
            return fr.link_id;
        }
    }
    0
}
