# v1.6 核心自绘字体（font-to-core）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把文本光栅化从 Unity 后端搬进 Rust 核心——核心用 ttf-parser 取轮廓 + ab_glyph 光栅 R8 + etagere 货架分配产字形 atlas + per-glyph UV，后端降为贴图上传器。补齐"引擎无关纯核心"唯一破例。

**Architecture:** 新增 Stage 持有的可变 `GlyphAtlas`（单物理 etagere，key=`(font_id,glyph_id,size_px,effect_sig)`，增量分配不 repack、多页）。text 节点塌进普通 `NodePayload::Mesh`（program=1），UV 指向 atlas，atlas 纹理引用走合成路径 `loomgui://font-atlas/...` intern 进现有 path_idx 表。blob v9→v10 删 text_arena/text_off/text_len + Text 变体。新增 3 个 atlas FFI（pull 脏页/拉 R8/清脏）。Unity：`LoomStage.Tick` 在 Sync 前挂 `SyncFontAtlas`（R8→Texture2D→Sprite.Create→SpriteResolver 缓存），shader ALPHA_MASK 采样 `.a`→`.r`。删 `TextRasterizer.cs` + 坑 113 补偿链 + G6 双源 Font asset。measure 保持纯函数。

**Tech Stack:** Rust core（ttf-parser 0.20 + ab_glyph_rasterizer 0.1 + etagere 0.3）+ csbindgen FFI + Unity 6.5 C#（URP）。本机唯一编码机（cargo 编 .dll + commit + push），家里机 PlayMode 验收。

**Spec:** `docs/superpowers/specs/2026-07-07-v1.6-font-to-core-design.md`（权威）。RmlUi 取证见 `docs/roadmap/rmlui-research.md §1`。

## Global Constraints

- **measure 保持纯函数**（spec §5.2）：光栅 + atlas 分配是状态ful副作用，放 Stage render build 期，**不进 measure_text**（taffy MeasureFunc 反复调，须零副作用）。`text/layout.rs::measure_text` 只用 ttf-parser 度量。
- **FFI 入口绝不 panic**（坑 102）：atlas FFI getter 用 `match None → 写默认/空`，scene=None 早返。cdylib 里 `.unwrap()`/`.expect()` 会 non-unwinding abort 拖垮宿主（Unity 闪退）。
- **FFI 边界 enum 必须 `#[repr(uN)]`**（坑 34）；新增/改 FFI struct 须同步手补 C# 镜像（坑 35，csbindgen 不为 `#[repr(C)]` struct 生成 stub）；`size_of::<T>()` 断言 ABI struct 尺寸。
- **dll 闭环**（坑 10/100）：改 Rust blob/ABI 后 `cargo build -p loomgui_ffi_c --release` + 拷 dll + `nm/findstr` 查新符号在 dll + `md5sum` 核对入库 dll。拷 dll 时 Unity 须关着（锁 dll）。**blob v10 是 ABI 大改，家里机干净 pull 须重编 .dll**。
- **Rust→Unity .dll 原子提交**：blob v10（Rust）+ `FrameBlob.cs` C# 镜像必须**同一 commit**，否则家里机 pull 后 Unity 读垃圾（Rust 产 v10、C# 还按 v9 解析）。
- **坑号只进 docs/pitfalls.md，不进代码注释**（CLAUDE.md）。代码注释上线品质：自包含、说 WHY、不引用内部编号。
- **fence_contract 门**（CLAUDE.md）：`cargo test -p loomgui_core fence_contract` build .dll 前必跑、改 apply_decl/选择器后必跑。本 plan 不碰围栏，门应保持绿。
- **API 适配方法论**（CLAUDE.md）：etagere 0.3 / ab_glyph_rasterizer 0.1 的 API 常与草稿不符——遇编译错按 crate 实际源码（`~/.cargo/registry/src/<crate>-<ver>/src/`）调，**勿硬改依赖版本**。T1 含"读 registry src 确认 API"步骤。
- **改 parse-time 逻辑必重打 pkg**（坑 66）：本 plan 是 runtime 改（render/layout measure/text），改 .dll 即可；不动 parse/dom/mapping。
- **两台机串行**：本机 build+commit+push；家里机 PlayMode 逐项验收（坑 131-133 教训：SDD 单测绿 ≠ 集成对，CSS 语义集成只在 PlayMode 显现）。

```rust
use std::collections::HashMap;

const PAGE_SIZE: i32 = 4096; // 4096² R8 = 16MB，容 3000-4000 CJK @48px

pub struct GlyphAtlas {
    pages: Vec<AtlasPage>,
    cache: HashMap<GlyphKey, GlyphRect>,
    dirty: Vec<u32>,
}

struct AtlasPage {
    allocator: etagere::Atlas,
    width: u32,
    height: u32,
    pixels: Vec<u8>, // R8，w*h
}

impl GlyphAtlas {
    pub fn new() -> Self { GlyphAtlas { pages: Vec::new(), cache: HashMap::new(), dirty: Vec::new() } }

    pub fn ensure(&mut self, face: &Face, key: GlyphKey) -> GlyphRect {
        if let Some(r) = self.cache.get(&key) { return *r; }
        let (pixels, gw, gh, _bearing) = rasterize_glyph(face, key.glyph_id, key.size_px);
        let rect = self.allocate(key, gw, gh);
        // blit 光栅像素进页缓冲
        let page = &mut self.pages[rect.page as usize];
        let stride = page.width as usize;
        for y in 0..gh as usize {
            for x in 0..gw as usize {
                let dx = (rect.px_x as usize) + x;
                let dy = (rect.px_y as usize) + y;
                page.pixels[dy * stride + dx] = pixels[y * gw as usize + x];
            }
        }
        if !self.dirty.contains(&(rect.page)) { self.dirty.push(rect.page); }
        let uv = GlyphRect { page: rect.page, u0: rect.px_x as f32 / page.width as f32,
            v0: rect.px_y as f32 / page.height as f32,
            u1: (rect.px_x + gw) as f32 / page.width as f32,
            v1: (rect.px_y + gh) as f32 / page.height as f32 };
        self.cache.insert(key, uv);
        uv
    }
    // allocate / dirty_pages / clear_dirty / page_bytes 见下...
}
```
> `allocate` 返回内部像素坐标（含 `px_x/px_y`），需一个内部 struct（`AllocRect{page,px_x,px_y}`）再转 UV。`rasterize_glyph` 见 Step 5。`pages[rect.page]` borrow：先 `let page_idx = ...; let alloc_rect = ...;` 拿到不可变快照再 `&mut self.pages[page_idx]`，避免借冲突。多页 `allocate`：现有页 `allocate(Size::new(gw,gh))` 失败 → push 新 `AtlasPage` 再分配（T8 完整多页，T1 先单页 + 满了 push 第二页即可）。

- [ ] **Step 5: 实现 rasterize_glyph（ttf-parser outline → ab_glyph 光栅 → R8）**

加私有函数：
```rust
/// 光栅单字形 → R8 像素 + 尺寸 + bearing。缺字（gid0 空）→ 返 tofu 框（确定性）。
fn rasterize_glyph(face: &Face, gid: u16, size_px: u16) -> (Vec<u8>, u32, u32, (f32,f32)) {
    let units = face.units_per_em() as f32;
    let scale = size_px as f32 / units;
    // outline 收集器：实现 ttf_parser OutlineBuilder，转发到 ab_glyph_rasterizer
    let mut builder = OutlineToRaster::new(scale);
    let has_outline = face.outline_glyph(ttf_parser::GlyphId(gid), &mut builder).is_ok();
    if !has_outline || builder.empty {
        return tofu_box(size_px); // 确定性缺字 fallback
    }
    let (w, h, off_x, off_y) = builder.pixel_bounds(size_px);
    let mut raster = ab_glyph_rasterizer::Rasterizer::new(w as usize, h as usize)
        .expect("raster size");
    builder.flush_to(&mut raster); // 按 Step 1 确认的 API：draw_line/draw_quad/draw_cubic
    let mut px = vec![0u8; (w * h) as usize];
    raster.for_each_pixel_2d(|x, y, cov| {
        px[y * w as usize + x] = (cov.min(1.0).max(0.0) * 255.0) as u8;
    });
    (px, w, h, (off_x, off_y))
}

fn tofu_box(size_px: u16) -> (Vec<u8>, u32, u32, (f32,f32)) {
    // 确定性方框：边宽 ~1px，advance 不在此管（advance 在 layout.rs）
    let w = (size_px as f32 / 3.0).max(2.0) as u32;
    let h = (size_px as f32 * 2.0 / 3.0).max(4.0) as u32;
    let mut px = vec![0u8; (w * h) as usize];
    for x in 0..w { px[x] = 0xdd; px[((h-1)*w+x) as usize] = 0xdd; } // 上下边
    for y in 0..h { px[y*w] = 0xdd; px[(y*w+w-1) as usize] = 0xdd; }   // 左右边
    (px, w, h, (1.0, h as f32))
}
```
> `OutlineToRaster` 实现 `ttf_parser::OutlineBuilder`（`move_to/line_to/quad_to/curve_to/close`），收集 scaled 段后 `flush_to` 调 rasterizer 的 `draw_line/draw_quad/draw_cubic`。**API 按 Step 1 registry src 确认**——若 `Rasterizer` 是 closure 式 `draw_curve(|r| {...})`，包一层。`pixel_bounds` 用 outline 的 bbox（`face.glyph_bounding_box` × scale）取整 + padding。

```rust
/// 把 TextLayout 每字形展成 quad mesh：4 顶点 + 6 索引，UV 指向核心 atlas。
/// 顶点 = pen 坐标 + glyph bbox（bearing）；颜色烤顶点（alpha 走 _Alpha uniform 不烤）。
fn build_text_mesh(
    layout: &crate::text::layout::TextLayout,
    font_id: u32,
    font_size: f32,
    color: [f32; 4],
    atlas: &mut GlyphAtlas,
    font: &crate::text::layout::Font,
) -> (Vec<[f32; 2]>, Vec<[f32; 2]>, Vec<[f32; 4]>, Vec<u32>) {
    let mut verts = Vec::new();
    let mut uvs = Vec::new();
    let mut indices = Vec::new();
    let face = &font.face;
    for line in &layout.lines {
        for run in &line.runs {
            for g in &run.glyphs {
                let key = GlyphKey { font_id, glyph_id: g.glyph_id,
                    size_px: font_size.round().max(1.0) as u16, effect_sig: 0 };
                let r = atlas.ensure(face, key);
                // quad 坐标：pen(g.x, line.baseline) + bearing → 4 角（顶到 baseline）
                let left = g.x + g.bearing_x;
                let top = line.baseline + g.bearing_y;   // bearing_y 顶到 baseline（layout.rs:347-351）
                // 字形像素宽高从 UV×atlas 页尺寸反推（或 atlas.ensure 附带 gw/gh——T1 GlyphRect 可加 px_w/px_h）
                let (gw, gh) = atlas.glyph_pixel_size(key); // 见 Step 5
                let right = left + gw;
                let bottom = top - gh;
                let base = verts.len() as u32;
                verts.push([left, bottom]); verts.push([right, bottom]);
                verts.push([right, top]);    verts.push([left, top]);
                uvs.push([r.u0, r.v1]); uvs.push([r.u1, r.v1]); // V 翻转：atlas 顶在下
                uvs.push([r.u1, r.v0]); uvs.push([r.u0, r.v0]);
                for &c in color.iter() { /* 4 顶点同色 */ }
                colors.extend(std::iter::repeat(color).take(4));
                indices.extend_from_slice(&[base, base+1, base+2, base, base+2, base+3]);
            }
        }
    }
    (verts, uvs, colors, indices)
}
```
> `colors` 变量在 helper 内声明（`let mut colors = Vec::new();`）。UV V 翻转方向按 Unity TextRasterizer 现状（BL/TL/TR/BR，`TextRasterizer.cs:62-77`）对齐——后端 quad 顶点序 BL,TL,TR,BR，UV 同序。**实测校准**：PlayMode 看 text 不上下颠倒即对（坑 113 类偶现，dump_text example 验）。

```rust
/// 拉脏页 page_idx 列表（写入 out，返实际数）。atlas 未用/无 scene → 0。
pub fn font_atlas_dirty_pages(&self, out: &mut [u32]) -> usize {
    let dirty = self.glyph_atlas.dirty_pages();
    let n = dirty.len().min(out.len());
    out[..n].copy_from_slice(&dirty[..n]);
    n
}
/// 读某页：尺寸 + R8 像素。buf_len 不够返所需大小（双调法），够则写 buf 返字节数。
/// 无此页 → 返 0（out_w/out_h 不写）。
pub fn font_atlas_page(&self, page: u32, out_w: &mut u32, out_h: &mut u32, out: &mut [u8]) -> usize {
    let (bytes, w, h) = self.glyph_atlas.page_bytes(page);
    let needed = (w * h) as usize;
    if out.len() < needed { return needed; } // 双调：caller 扩 buf 重调
    out[..needed].copy_from_slice(bytes);
    *out_w = w; *out_h = h;
    needed
}
/// 清脏页（backend 拉完调）。
pub fn font_atlas_clear_dirty(&mut self) { self.glyph_atlas.clear_dirty(); }
```

```rust
/// 拉脏页 page_idx 列表。null/无 scene → 返 0。对齐 get_node_layout_rect 惯例（无状态码）。
#[no_mangle]
pub extern "C" fn loomgui_stage_font_atlas_dirty_pages(
    h: *const StageHandle, out: *mut u32, max: usize,
) -> usize {
    if h.is_null() || out.is_null() { return 0; }
    let sh = unsafe { &*h };
    let buf = unsafe { std::slice::from_raw_parts_mut(out, max) };
    sh.stage.font_atlas_dirty_pages(buf)
}

/// 读某页 R8 像素 + 尺寸。buf_len 不够返所需大小（双调）。null/无此页 → 0。
#[no_mangle]
pub extern "C" fn loomgui_stage_font_atlas_page(
    h: *const StageHandle, page: u32,
    out_w: *mut u32, out_h: *mut u32, out_buf: *mut u8, buf_len: usize,
) -> usize {
    if h.is_null() { return 0; }
    let sh = unsafe { &*h };
    let (mut w, mut hgt) = (0u32, 0u32);
    // 先探所需大小（传空 buf）
    let needed = sh.stage.font_atlas_page(page, &mut w, &mut hgt, &mut []);
    if buf_len < needed { return needed; } // 双调
    let buf = unsafe { std::slice::from_raw_parts_mut(out_buf, buf_len) };
    let n = sh.stage.font_atlas_page(page, &mut w, &mut hgt, buf);
    if !out_w.is_null() { unsafe { *out_w = w; } }
    if !out_h.is_null() { unsafe { *out_h = hgt; } }
    n
}

#[no_mangle]
pub extern "C" fn loomgui_stage_font_atlas_clear_dirty(h: *mut StageHandle) {
    if h.is_null() { return; }
    let sh = unsafe { &mut *h };
    sh.stage.font_atlas_clear_dirty();
}
```

```csharp
    if (n > dirty.Length) { dirty = new uint[n]; n = Native.loomgui_stage_font_atlas_dirty_pages(_stage, dirty, dirty.Length); }
    for (int i = 0; i < n; i++)
    {
        uint page = dirty[i];
        // 双调：先探所需 byte 数。
        uint w = 0, h = 0;
        int needed = Native.loomgui_stage_font_atlas_page(_stage, page, ref w, ref h, null, 0);
        if (needed <= 0) continue;
        byte[] buf = ArrayPool<byte>.Shared.Rent(needed);   // 独立 buf，不挤 _frameBuf
        try
        {
            int got = Native.loomgui_stage_font_atlas_page(_stage, page, ref w, ref h, buf, needed);
            if (got != needed) continue;
            // 上传 R8 Texture2D
            var tex = new Texture2D((int)w, (int)h, TextureFormat.R8, mipChain: false);
            tex.LoadRawTextureData(buf, got);   // 或 SetPixelData<byte>(buf, 0)
            tex.Apply(updateMipmaps: false, makeNoLongerReadable: true);
            string path = $"loomgui://font-atlas/f{0}/p{page}"; // font_id 暂 0（单字体）；多字体见 T8
            _sprites.RegisterFontAtlasPage(path, tex);   // _sprites 是 SpriteResolver（LoomStage.cs:133-136 注入）
        }
        finally { ArrayPool<byte>.Shared.Return(buf); }
    }
    Native.loomgui_stage_font_atlas_clear_dirty(_stage);   // 注：clear_dirty 需 *mut，_stage 是 StageHandle*，确认签名
}
```
Tick 内插入（`:176` 附近）：
```csharp
    SyncFontAtlas();   // borrow_frame 后、_pool.Sync 前
    _pool.Sync(blob, ...);
```
> `font_id` 在路径里：单字体场景 v1.6 恒 default font_id（FontTable.font_id(None)）；多字体 T8 扩（脏页需带 font_id，或路径用 family）。**v1.6 单字体先硬编 default font_id**——读 `_stage` 不可得 font_id，需 LoomStage 持 `_defaultFontId`（RegisterFont 时记）。或 atlas 脏页 FFI 附带 font_id（T5 扩 dirty_pages 返 (page,font_id) pair）。**推荐 v1.6**：单字体，路径 `loomgui://font-atlas/p<page>`（不带 font_id），T8 多字体再扩 key。
> `clear_dirty` 签名是 `*mut StageHandle`——`_stage` 是 `StageHandle*`，直接传（unsafe）。`Native.loomgui_stage_font_atlas_clear_dirty(ref *_stage)` 或按 csbindgen 生成签名调（坑 35）。
