# v1.8 文字效果 + 装饰视觉 设计

> brainstorming 定稿（2026-07-08）。一个 v1.8 号，内部分两段 task（装饰视觉快赢 + 文字效果 FontEffect），跟 v1.7 同模式不拆版本号。
> 权威契约 = `loomgui_core/tests/fence_contract.rs`；本 spec 是设计意图 + 实现真相，不一致时测试赢（同项目围栏原则）。
> 对标依据 = `docs/roadmap/rmlui-research.md` §2/§3/§6 + RmlUi FontEffect 源码取证（见附录 A）。

## 1. 背景与目标

### 1.1 为什么做

v1.6 把字体搬进核心（自绘字形 atlas），v1.7 在其上做了富文本。v1.8 兑现 v1.6 预留的"阶段 c FontEffect"地基 + 补齐 AI 必写却坏/缺的装饰视觉。

roadmap §2.2（`docs/roadmap/roadmap.md:110`）定义 v1.8 = **文字效果 + 装饰视觉**。两条线：

- **装饰视觉**：AI 必写 CSS（`border`/`linear-gradient`/`box-shadow`/`sepia`/圆角裁剪）却死字段/静默忽略/坏掉，违背 AI 可预测性契约。低风险快赢（纯几何/shader）。
- **文字效果**：v1.6 atlas key 已预留 `effect_sig`（`text/atlas.rs:36`），v1.8 启用，做描边/发光/blur/阴影/渐变字 + 装饰线增强。

### 1.2 首要判据

**AI 可预测性**（项目核心目的）。DSL 决策的首要判据 = "AI 读这段 HTML 能否正确预测渲染出的 UI"。具体到 v1.8：

- 标准 CSS 能干净映射 + AI 强先验的效果 → **跟标准 CSS**（阴影/渐变字/描边/装饰线）。
- 标准 CSS 表达不了的字形位图后处理 → **私有 `font-effect`**（发光/blur），且只用在 AI 没有先验处，避免和先验打架。

### 1.3 非目标（推后）

- **border 四边不等宽**：v1.8 只做单值四边同宽。四边不等宽推后到 v1.x 控件/补丁档（待定号）。须改 roadmap 标明。
- **box-shadow 真实 blur**：v1.8 box-shadow 只做几何近似（无 blur）。真实 blur 需离屏 RT，排 v1.14+。须在 roadmap §2.4 标明。
- **多 stop / 斜角度 linear-gradient**：v1.8 只支持 2 色 + 4 方向（to right/left/top/bottom）。多 stop/斜角度需 shader，推后。
- **filter:blur / 真实 box-shadow / drop-shadow / 任意形状 mask**：需离屏 RT，排 v1.14+。
- **彩色字形 emoji（COLR）**：推 v1.8+（roadmap 已记）。
- **text-decoration-style: wavy**（波浪线）：v1.8 不做。
- **border-style: dashed/dotted/double**（边框样式）：v1.8 只 solid，余静默忽略。

## 2. 关键决策（brainstorming 定稿，含理由）

### 2.1 一个 v1.8 全做，分两段不拆版本号

装饰视觉（纯几何/shader）+ 文字效果（CPU 字形后处理）技术栈正交，但同属"视觉质量"主题，写进一个 spec，内部分段 task（段 1 装饰快赢 + 段 2 文字效果），跟 v1.7 同模式。对齐 roadmap 单号 + 文本线 v1.6→v1.7→v1.8 连续不被打断。

### 2.2 DSL 混合：标准 CSS 优先，私有只补标准表达不了的

| 效果 | DSL | 语法 | AI 先验 | 映射 |
|---|---|---|---|---|
| 阴影 | 标准 CSS | `text-shadow: ox oy blur color`（多值逗号叠加）| 强 | FontEffect shadow = offset + 高斯 blur |
| 渐变字（2色）| 标准 CSS | `background: linear-gradient(to right,#f00,#00f); -webkit-background-clip: text; color: transparent` | 强 | per-glyph quad 顶点两色插值 |
| 描边 | 标准 CSS | `-webkit-text-stroke: w color` | 强（事实标准）| FontEffect erode 位图，**内侧吃字**（对齐浏览器语义）|
| 装饰线 | 标准 CSS | `text-decoration: underline dashed #f00 2px`（CSS3 shorthand）| 中强 | 扩 RichDeco + 装饰线 mesh |
| 发光 | 私有 | `font-effect: glow(w color)` | 弱（无私有冲突）| FontEffect dilation + 高斯 blur |
| blur | 私有 | `font-effect: blur(w)` | 弱（无私有冲突）| FontEffect 可分离高斯两 pass |

**分界原则**：私有 `font-effect` 只用在标准 CSS 无表达处（发光/字形 blur），AI 没有错误先验可冲突。标准 CSS 属性（border/text-shadow/-webkit-text-stroke/text-decoration/linear-gradient）对齐浏览器语义，AI 预测准。

### 2.3 描边内侧吃字（不做外侧膨胀）

`-webkit-text-stroke` 是事实标准，语义 = 内侧吃字（描边向内填充，吃字形边缘）。LoomGUI 对齐此语义，AI 写 `-webkit-text-stroke: 1px #000` 期望浏览器效果，LoomGUI 渲染 = 预期。粗描边糊死是 AI 自己写粗了的事，LoomGUI 不替 AI 操心。内侧吃字实现 = erode 位图（dilation 反向，统一卷积管线），不做外侧 dilation 膨胀。

### 2.4 渐变字只支持 2 色 + 4 方向

per-vertex 两色插值 = 字形 quad 4 顶点两色。只对应 `linear-gradient(to right/left/top/bottom, colorA, colorB)`。多 stop/斜角度 per-vertex 做不了（要 shader），编译期报错不让 AI 误以为支持。渐变字不进 atlas（顶点色），字形位图仍是 base（effect_sig=0）。

### 2.5 FontEffect 走 atlas effect_sig 分槽 + layer 叠放

v1.6 已在 `GlyphKey` 预留 `effect_sig: u64`（恒 0）。v1.8 启用：每个 effect 配置 hash 成 sig，同字形不同 effect → 不同 sig → atlas 不同槽。`atlas.ensure` 内 `rasterize_glyph` 出 R8 位图后，按 sig 查 effect 做后处理。effect layer 按 Back/Front 分区叠放（抄 RmlUi）：`[Back: shadow/glow] → [base 文字] → [Front: blur/stroke]`，合成靠绘制顺序 + 现有 alpha blend，无新 blend mode。

## 4. DSL 设计（AI 写什么 + 围栏改动）

权威真相源 = `loomgui_core/tests/fence_contract.rs`。本节定口径，实现时落测试。

### 4.1 新增进围栏的属性

| 属性 | 值约束 | 围栏门测试 |
|---|---|---|
| `border` / `border-color` / `border-width` | 单值（四边同宽），`border-style` 仅 `solid` | 彩色边框渲染出环形带 |
| `background: linear-gradient(...)` | 2 色 + 4 方向（to right/left/top/bottom）| 2 色横/竖渐变渲染；多 stop/斜角度**编译期报错** |
| `box-shadow` | `ox oy spread color`，blur 半径**静默忽略** | 几何近似投影渲染 |
| `filter: sepia(...)` | 标准值，补棕褐矩阵（已 parse 占位，补矩阵）| sepia 不再退化 grayscale |
| `overflow: hidden` + `border-radius` | 组合触发圆角 SDF 裁剪 | 圆角裁剪渲染 |
| `text-shadow` | 标准 `ox oy blur color`，多值逗号叠加 | 阴影 + 多阴影叠加渲染 |
| `-webkit-text-stroke` | `width color`，内侧吃字 | 描边渲染 |
| `font-effect` | `glow(w color)` / `blur(w)`，私有，逗号叠加 | 发光/blur 渲染 |
| `text-decoration` shorthand | `line style color thickness`，line=underline/line-through/overline，style=solid/dashed/dotted/double | 虚线/双线/独立色渲染 |

### 4.2 围栏外静默忽略（`apply_decl` 返 false，不报错）

- `border-style: dashed/dotted/double`（v1.8 只 solid）
- `box-shadow` 的 blur 半径
- `linear-gradient` 之外的渐变函数（`radial-gradient`/`conic-gradient`）
- `text-decoration-style: wavy`
- `-webkit-text-stroke` 之外的 webkit 私有文本属性

### 4.3 围栏外编译期报错（打包器拒收，给 AI 明确反馈）

- `linear-gradient` 多 stop（>2 色）或斜角度（非 4 方向）— 避免 AI 误以为能出多 stop
- `font-effect` 未知 type（非 glow/blur）— 私有语法严格
- `font-effect` 参数缺括号 — 对齐 RmlUi `font-effect: type(props)`
- **渐变字三件套残缺**：
  - `background-clip: text` 单独出现（无 `linear-gradient` 背景）→ 报错（意图渐变字但缺背景）
  - `background: linear-gradient` + `background-clip:text` 但缺 `color:transparent` → 报错（缺透明色，字形被文本色盖住）
  - `background: linear-gradient` **无** `background-clip:text` → 正常渐变背景，不报错（合法用法）

### 4.4 AI 可预测性护栏

- 标准 CSS 属性 → LoomGUI 渲染对齐浏览器语义，AI 预测准。
- 私有 `font-effect` → 只用在标准 CSS 无表达处，AI 无错误先验可冲突。
- 多 stop 渐变 / 渐变字三件套残缺 → 编译期报错给明确反馈，不让 AI 误以为生效。

## 5. 架构总览（数据流）

v1.8 两个正交子系统，共享"视觉质量"主题，走两条独立管线。

### 5.1 子系统 A — 装饰视觉（render mesh 层，纯几何/shader）

```
CSS 属性 → 打包器 parse/mapping（resolve 到 base_style）
  → render build 期按 base_style 生成额外 mesh：
     彩色边框 → border_ring 环形三角带（独立 RenderNode，叠背景上、子节点下）
     2色渐变 → quad 四角 per-vertex 两色
     box-shadow → 外扩圆角 quad + 四周顶点 alpha 渐隐（独立 RenderNode，节点下层）
     sepia → filter 色矩阵补一棕褐矩阵（复用现有 color_matrix 通道）
     圆角 SDF 裁剪 → shader 扩 _ClipBox 成圆角 SDF + corner-radius uniform
     九宫格修复 → mesh.rs nine_slice 改 % resolve + 按比例分 + 接缝取整
  → blob 透传（border/gradient/box-shadow 走 mesh_arena；sepia 走现有 color_matrix 列；圆角裁剪走 shader uniform）
```

**不碰 atlas**（边框/渐变/box-shadow 都是 quad mesh，sepia 是色矩阵，圆角是 shader）。

### 5.2 子系统 B — 文字效果（text atlas 层，字形位图后处理）

```
CSS 属性 → 打包器 parse/mapping → RichRun 携带 effect 配置
  → render build 期，每字形构造 GlyphKey 时 effect_sig = hash(effect配置)
  → atlas.ensure(face, key)：rasterize_glyph 出 R8 位图后，按 effect_sig 查 effect，
     对位图做后处理（dilation/erode/gaussian_blur/clone_offset），输出新位图（可能扩边界）
  → atlas 按 (font,gid,size,effect_sig) 分槽缓存
  → build 期按 effect layer 顺序画字形 quad：
     [Back: shadow/glow] → [base 文字] → [Front: blur/stroke]
  → 渐变字 per-vertex 两色（不进 atlas）
  → 装饰线增强：RichDeco 扩 style/color/thickness，build 期按样式画 mesh
```

**只碰 atlas + 文本 mesh**（不改 render 的非文本路径）。

### 5.3 两条管线边界

- 装饰视觉不碰 atlas；文字效果只碰 atlas + 文本 mesh。
- 唯一交叉点：渐变字 per-vertex 两色 是文本 mesh 层（字形 quad 顶点色），归子系统 B build 期，但不进 atlas（atlas 存字形位图，渐变是顶点色）。

### 5.4 FFI / blob 契约

- **倾向 blob 不 bump 版本**（同 v1.7 策略）。effect_sig 是 atlas 层（不影响 blob）；border/box-shadow/渐变/装饰线都是 mesh_arena 数据（更多 mesh，blob 列零改）；sepia 复用 color_matrix；圆角裁剪是 shader uniform。
- 唯一可能加列：圆角裁剪的 corner-radius（若现有 `_ClipBox` uniform 通道装不下）。实现时核实现有 clip 通道能否扩，能则零列改；不能则加一列（minor，blob 不必 bump 大版本）。

## 6. 子系统 A 装饰视觉 — 各特性实现细节

### 6.1 彩色边框（修死字段）

- **现状**：`border_width`（`resolved.rs:125`，进 taffy border box 占布局）+ `border_color`（`resolved.rs:124`，render 零引用 = 死字段）。`mapping.rs:391/518` 已 parse。
- **实现**：`render/mesh.rs` 新增 `border_ring(rect, radii, width, color)` — 生成"外轮廓减内轮廓"环形三角带。四角随圆角弧分段。独立 RenderNode（program=0 顶点色），叠背景之上、子节点之下。
- **边框宽度**：v1.8 单值四边同宽（`border_width: f32` 现状）。四边不等宽推后（§1.3）。
- **围栏**：`border-color`/`border-width`/`border` shorthand 进围栏（已 parse，补 render 即活）。`border-style` 仅 `solid`，余静默忽略。

### 6.2 2色渐变（背景）

- **实现**：`mesh.rs` 的 `quad`（四角同色）扩成接受 4 角独立色。`background: linear-gradient(to right, #f00, #00f)` → 左两顶点 #f00、右两顶点 #00f。4 方向。
- **围栏**：`linear-gradient` 限 2 色 + 4 方向，多 stop/斜角度编译期报错。

### 6.3 box-shadow 几何近似

- **实现**：生成比 rect 大 spread 的圆角 quad（独立 RenderNode，画在节点下层 = sort_key 更小），四周顶点 alpha 从 shadow-color 向 0 渐隐。无 blur（真实 blur 需 RT 排 v1.14+）。
- **DSL**：标准 `box-shadow: offset-x offset-y spread color`（blur 半径静默忽略，文档说明）。

### 6.4 sepia 补全

- **现状**：`mapping.rs:117-121` 退化成 grayscale（ponytail 占位）。
- **实现**：补一棕褐 tint 矩阵（标准 sepia 矩阵），走现有 color_matrix 通道（shader 透传，program 3/4）。

### 6.5 圆角 SDF 裁剪

- **现状**：裁剪是矩形 AABB（`batch.rs` + shader `_ClipBox`）。
- **实现**：shader 扩 `_ClipBox` 成圆角矩形 SDF + `corner-radius` uniform。`overflow:hidden` + `border-radius` 时，clip 用 SDF 而非 AABB。`col.a *= sdf_rounded_box(...)`。加 `CLIPPED_ROUNDED` keyword 变体 + `_CornerRadius` uniform。
- **后端**：`LoomGUI-Unlit.shader` 改。**这是装饰组唯一动后端 shader 的项**。

### 6.6 九宫格修复（修 bug）

三处硬修（rmlui-research §3.3）：
- **`%` resolve**：render 期把比例乘 `src_w/src_h`（对照 radii resolve 闭包）。修 `mapping.rs:149-151` 存 0.25 当像素用。
- **按比例分**：`mesh.rs:190` `slice.left.min(w*0.5)` → `left/(left+right)*w`（借 NinePatch.cpp:84-95）。
- **接缝取整**：内切片线 round（注意 y-flip，可能放后端更合适）。
- **围栏**：零改（`border-image-slice` 已在围栏，修 render 即活）。补一条 render 期单测（之前只锁 parse，漏网原因）。

## 7. 子系统 B 文字效果 — FontEffect 管线 + 各 effect

### 7.1 核心机制：atlas effect_sig 分槽 + layer 叠放

v1.6 已在 `GlyphKey` 预留 `effect_sig: u64`（`text/atlas.rs:36`，恒 0，注释"为 v1.8 FontEffect 预留"）。v1.8 启用：
- 每个 effect 配置（type + 参数）hash 成 `effect_sig`。同字形不同 effect → 不同 sig → atlas 不同槽。
- `atlas.ensure(face, key)` 内部：`rasterize_glyph` 出 R8 位图后，按 `key.effect_sig` 查 effect 表，对位图做后处理，输出新位图（可能扩边界，需重算 gw/gh + 重 allocate）。

**effect layer 叠放顺序**（抄 RmlUi Back/Front 分区）：
```
[Back: shadow/glow layer]  →  [base 文字]  →  [Front: blur/stroke layer]
```
build 期按 layer 顺序画字形 quad，每层用各 layer 的颜色（base 用文本色，shadow/glow 用 effect 色）。合成靠绘制顺序 + 现有 alpha blend（同 RmlUi，无新 blend mode）。

### 7.2 逐 effect 映射

| effect | DSL | 算法 | layer | atlas 后处理 |
|---|---|---|---|---|
| 阴影 | `text-shadow: ox oy blur color`（标准，多值叠加）| offset + 高斯 blur | Back | clone 字形位图 → 高斯 blur → 偏移存为新槽 |
| 描边 | `-webkit-text-stroke: w color`（标准，内侧吃字）| erode 位图（dilation 反向）| Front | 光栅后对位图 erode w 像素，描边色填充 erode 区 |
| 发光 | `font-effect: glow(w color)`（私有）| dilation + 高斯 blur | Back | dilation 圆形卷积 → 高斯 blur |
| blur | `font-effect: blur(w)`（私有）| 可分离高斯两 pass | Front | 可分离高斯两 pass |
| 渐变字 | `linear-gradient(2色4方向)`+`background-clip:text`+`color:transparent`（标准）| per-vertex 两色 | base | 不进 atlas（顶点色）|

### 7.3 关键技术决策

1. **blur 复用**：shadow 的 blur、glow 的 blur、blur effect 都是可分离高斯，抽共享 `gaussian_blur(bitmap, sigma)`。glow = dilation + blur，shadow = clone + blur + offset，blur = blur。
2. **描边 erode 位图**：`-webkit-text-stroke` 内侧吃字 = erode（dilation 反向，取字形 alpha 内缩 w 像素），描边色填充 erode 出的边界区。统一卷积管线（dilate/erode 同一框架正反）。
3. **effect_sig hash 输入**：`(effect_type, params)` hash。如 `shadow(2,2,4,#000)` → hash(type=shadow, ox=2, oy=2, blur=4, color=#000)。per-size 已在 key，不进 sig。多 effect 叠加 → 多个 layer，每层 sig 独立。
4. **多 effect 叠加**：`font-effect: glow(3px #ee9), blur(2px)`（私有逗号叠加）+ `text-shadow` 可同时存在。每个 effect 一个 layer，按 Back/Front 分区叠放。
5. **渐变字不进 atlas**：渐变字 = per-vertex 顶点色，字形位图仍是 base（effect_sig=0），quad 顶点色两色插值。

### 7.4 装饰线增强

`RichDeco` 从 `{underline: bool, strike: bool}`（`text/rich.rs:28`）扩成：
```rust
struct RichDeco {
    lines: TextDecoLines,      // underline / line_through / overline（位标记，可组合）
    style: TextDecoStyle,      // Solid / Dashed / Dotted / Double
    color: Option<[f32; 4]>,   // 独立色，None = run.color
    thickness: Option<f32>,    // 独立粗细，None = 字体 underline_thickness
}
```
CSS3 `text-decoration` shorthand 解析（`line style color thickness`）。build 期（`render/mod.rs:786-824` 现有装饰线段）按样式画 mesh：
- `solid` = 现有纯色 quad
- `dashed` = 分段 quad（每段 N px + 间隔）
- `dotted` = 分段小 quad
- `double` = 两条 quad（上下各一）
- 独立 color/thickness 覆盖字体 metrics

### 7.5 性能护栏（规避 RmlUi 自承短板）

- **atlas 增量**：v1.6 etagere 已增量分配不 repack，effect 字形同 base 字形走增量，**不全量重建**（规避 RmlUi `FontFaceLayer.cpp:22` 全量重建坑）。
- **卷积 O(N²) CPU 单线程**：effect 字形进 atlas 缓存（同 sig 只算一次），运行时无热路径卷积。Glow 三 pass 临时 buffer 复用（规避 RmlUi 每次分配）。
- **CJK 多 effect atlas 撑爆**：多 effect 字形数 = base 字形数 × effect 数。CJK 大量字形 + 多 effect 可能撑爆单页 → 多页溢出（v1.6 已支持）兜底。
- **高斯权重公式**：用标准 `exp(-x²/(2σ²))`，不用 RmlUi 非标准 `exp(-sqrt(x²)/two_variance)`。

## 8. 核心组件 + 接口改动（文件级）

### 8.1 新增模块

**`loomgui_core/src/text/font_effect.rs`**（新文件）：

## 附录 A：RmlUi FontEffect 体系取证

源码 `temp/RmlUi/`（只读）。完整 agent 报告存 session transcript。

**算法**：
- **描边**（`FontEffectOutline.cpp`）：dilation 圆形卷积（取 max，非方向克隆），kernel 圆形 `distance <= width` weight=1，边缘线性衰减抗锯齿。单 pass。`HasUniqueTexture=true`，`Layer=Back`。DSL `outline(width, color)`。
- **发光**（`FontEffectGlow.cpp`）：dilation + 可分离高斯，三 pass（outline → blur_x → blur_y）。临时 buffer 每次分配（v1.8 复用）。DSL `glow(width-outline, width-blur, offset-x, offset-y, color)`。
- **blur**（`FontEffectBlur.cpp`）：可分离高斯两 pass。权重 `gain * exp(-sqrt(x²)/two_variance)`（非标准，v1.8 改标准 `exp(-x²/(2σ²))`）。DSL `blur(width, color)`。
- **阴影**（`FontEffectShadow.cpp`）：clone-offset **无 blur**（太弱，v1.8 做 offset + 可选 blur）。`HasUniqueTexture=false`（复用 base 纹理）。DSL `shadow(offset-x, offset-y, color)`。
- **共享**：`ConvolutionFilter`（`ConvolutionFilter.cpp:42-88`）两种操作 `Sum`（高斯累加）/`Dilation`（取 max），只写 alpha 通道。`FillColorValuesFromAlpha`（alpha 复制到 RGB，premultiplied alpha，颜色由 vertex color 提供）。

**atlas layer 机制**：每 effect 独立 `FontFaceLayer`，按 `fingerprint` 缓存。Back/Front 稳定分区（`PropertyParserFontEffect.cpp:110-111`），configuration = `[Back effects] → [base] → [Front effects]`。合成靠绘制顺序 + premultiplied alpha over，无独立 blend mode。

**DSL**：私有 `font-effect: type(props)` 函数式，逗号叠加多 effect。非标准 CSS（不用 text-shadow/-webkit-text-stroke）。

**装饰线**：CSS2.1 最小实现（`ElementText.cpp:545-567`），keyword 仅 none/underline/overline/line-through，无虚线/双线/独立色/独立粗细。**v1.8 装饰线增强零参考价值，自研**。

**自承短板**（v1.8 规避）：
- `FontFaceLayer.cpp:22` 全量重建纹理 → v1.6 etagere 增量已规避。
- `FontEffectGlow.cpp:104-105` 临时 buffer 每次分配 → v1.8 复用。
- `ConvolutionFilter` 朴素 O(N²) 单线程 → v1.8 靠 atlas 缓存兜底（运行时无热路径）。
- Shadow 不支持彩色字形（RGBA8 return false）→ v1.8 atlas 是 R8，不受影响。

**完整对标结论**见 `docs/roadmap/rmlui-research.md` §2/§3/§6。
